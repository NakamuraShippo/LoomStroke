LoomStroke

マンガ・イラスト制作のための統合デジタルペイントアプリケーション

アプリケーション概要

LoomStroke は、ラスタ描画、ベクターパス、テキスト編集、複数ページ、外部プラグイン、AI 連携を同じ制作環境で扱うデジタルペイントアプリケーションです。作業中のファイルは .lstroke 形式で保存できます。

主要機能

  • 筆圧・チルト対応ブラシエンジン
  • レイヤーの不透明度・ブレンドモード管理
  • ベクターパス・パラメトリックシェイプ
  • 横書き・縦書きテキスト
  • ノンデストラクティブ・エフェクトレイヤー
  • マルチページドキュメント

AI 連携

  • ComfyUI ワークフロー統合
  • NanoBanana (Gemini) 画像生成
  • プロンプトエディタ・スニペット管理
  • LLM Gateway (OpenAI / Anthropic / Gemini)

アクティブツールの設定を表示するパネルです。メニューバー直下のバーモード (横一列) と、ドック内のパネルモード (縦配置) の 2 つのレイアウトを持ちます。

構成要素

  • プリセット行: プリセット選択コンボボックス + 保存/削除ボタン
  • Common Properties グループ: Size, Opacity, Hardness, Spacing, Flow 等 (ツール共通)
  • Tool Properties グループ: ツール固有のパラメーター
  • Actions コンテナ: ツール固有のアクションボタン/チェックボックス

ウィジェット自動生成: float/int → スライダー, bool → チェックボックス, enum → コンボボックス, color → カラーボタン

ブレンドモード

レイヤーブレンドは、選択中レイヤーの色を下のレイヤー群にどう合成するかを決めます。Opacity はブレンド結果全体の強さとして後から効きます。描画内容を変更せず表示合成だけを変えるため、色味の調整、光や影の追加、テクスチャ重ねに使います。

グループモード説明
Group onlyPass Throughグループ用です。子レイヤーをグループ内だけで閉じず、下のレイヤー群も含めた文脈で合成します。
NormalNormal通常合成です。上のレイヤーをそのまま重ね、不透明度で強さを調整します。
NormalDissolve半透明部分をランダムな点状に見せる合成です。ざらついたエッジや粒状の表現に向きます。
DarkenDarken上と下の暗い成分を優先します。明るい部分を残しにくく、影や暗部の追加に使います。
DarkenMultiply色を掛け合わせて暗くします。線画、影、紙目、汚れの重ねで最も扱いやすい暗色系モードです。
DarkenColor Burn下地を強く焼き込むように暗くし、彩度やコントラストも強めます。濃い影や強い質感に向きます。
DarkenLinear Burn明度を直線的に下げて暗くします。Color Burn より計算感のある強い暗部になります。
DarkenDarker Color合成後の色ではなく、上と下のうち暗い色を選びます。色の置き換えに近い暗色優先の結果になります。
LightenLighten上と下の明るい成分を優先します。暗い部分を消しながら光や明部を重ねたいときに使います。
LightenScreenMultiply の逆方向に働き、自然に明るくします。発光、ハイライト、煙、光素材の重ねに向きます。
LightenColor Dodge下地を強く明るくし、鮮やかな光を作ります。白飛びしやすいため Opacity で調整します。
LightenLinear Dodge (Add)色を加算して強く明るくします。光源、魔法効果、強い発光の表現に向きます。
LightenLighter Color上と下のうち明るい色を選びます。明色優先で素材を重ねたいときに使います。
ContrastOverlay下地の明暗を基準に Multiply と Screen を切り替えます。質感追加や陰影強調の定番です。
ContrastSoft LightOverlay より柔らかくコントラストを加えます。肌、布、微妙な陰影調整に向きます。
ContrastHard Light上のレイヤーを基準に強い明暗効果を加えます。はっきりした光と影を作ります。
ContrastVivid LightColor Burn と Color Dodge を組み合わせたように、強く鮮やかなコントラストを作ります。
ContrastLinear LightLinear Burn と Linear Dodge を組み合わせたように、明度を直線的に強く変化させます。
ContrastPin Light暗い部分と明るい部分を置き換えるように合成します。特殊な硬い質感や効果向けです。
ContrastHard Mix色を強く二値化したような結果に寄せます。ポスター調、ノイズ調、実験的な効果に向きます。
InversionDifference上と下の差分を表示します。位置合わせ確認、反転風の効果、特殊な色変化に使います。
InversionExclusionDifference より柔らかい差分合成です。反転感を抑えた特殊効果に向きます。
InversionSubtract下地から上の色を引いて暗くします。色を削るような効果や暗い特殊効果に使います。
InversionDivide下地を上の色で割るように明るくします。補正、抜き、強い明部変化の確認に使います。
ComponentHue上の色相だけを下地へ適用し、下地の明度と彩度を保ちます。色味だけ変えたいときに使います。
ComponentSaturation上の彩度だけを下地へ適用します。鮮やかさの追加や彩度を落とす調整に使います。
ComponentColor上の色相と彩度を下地へ適用し、下地の明度を保ちます。グレースケールの陰影に色を乗せる用途に向きます。
ComponentLuminosity上の明度だけを下地へ適用し、下地の色相と彩度を保ちます。陰影や明暗だけを差し替えます。

ブレンドモードはレイヤー、エフェクトレイヤー、グループ合成、PSD エクスポートの表示結果に関係します。モード変更はキャンバスを再合成しますが、レイヤーのピクセルそのものは書き換えません。

AI Effect Layer AI EFFECT

AI Effect Layer は、.lsfx プリセットをレイヤーとしてキャンバスに配置し、ComfyUI Gateway または NanoBanana Gateway へ入力レイヤーとパラメーターを渡して画像を生成する機能です。通常の ComfyUI パネルや NanoBanana パネルとは別に、Layer Panel / Effect Panel / AI Effects Manager と連携して動きます。

基本の流れ

  1. AI メニューの AI Effect Presets... で AI Effects Manager を開く
  2. プリセットを右クリックして Add AI Effect Layer を選ぶ
  3. Layer Panel で AI Effect レイヤー配下の Slot 行に入力レイヤーを割り当てる
  4. Effect Panel でパラメーター、出力先、Generate を操作する
  5. 生成結果を AI Effect レイヤー自身、または真上の新規出力レイヤーへ反映する
項目内容
レイヤー種別layer_type="ai_effect"
プリセット形式.lsfx。ZIP 内に manifest、Gateway 設定、アイコンなどを保持
対応 GatewayComfyUI Gateway / NanoBanana Gateway
保存.lstroke v1.2 の ai_effect payload として状態を保持

外部サービス接続が必要な Gateway は、Preferences の外部サービス許可と API キー / 接続先設定が揃っている場合のみ実行できます。
