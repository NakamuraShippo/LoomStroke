LoomStroke

Um aplicativo integrado de pintura digital para produção de mangá e ilustração

Visão geral do aplicativo

O LoomStroke é um aplicativo de pintura digital que reúne pintura raster, caminhos vetoriais, edição de texto, múltiplas páginas, plugins externos e integração de IA em um único espaço de produção. Os arquivos de trabalho podem ser salvos em.lstrokeformato.

Principais recursos

  • Motor de pincel com suporte a pressão e inclinação
  • Gerenciamento de opacidade da camada e modo de mesclagem
  • Caminhos vetoriais e formas paramétricas
  • Texto horizontal e vertical
  • não destrutivo efeito camadas
  • Documentos multipágina

AI integração

  • Integração de fluxos de trabalho do ComfyUI
  • NanoBanana (Gemini) imagem geração
  • Editor de prompts e gerenciamento de snippets
  • LLM Gateway (OpenAI / Anthropic / Gemini)

Layout da tela

A janela principal é composta pelas áreas abaixo. Os painéis podem ser organizados livremente por arrastar e soltar, e também podem ser combinados como abas.

Propriedades da ferramenta painel painel

Painel que mostra as configurações da ferramenta ativa. Ele tem duas disposições: modo barra logo abaixo da barra de menus e modo painel dentro de um dock.

Componentes

  • Preset linha: Preset seleção combo caixa + salvar/excluir botões
  • Common Properties grupo: tamanho, opacidade, Hardness, Spacing, Flow, e other common ferramenta configurações
  • Propriedades da ferramenta grupo: ferramenta-specific parâmetros
  • Ações container: específicos da ferramenta botões de ação e caixas de seleção

automático controle geração: float/int -> controle deslizante, bool -> caixa de seleção, enum -> combo caixa, cor -> cor botão

Modo de mesclagems

A mesclagem de camadas controla como a camada selecionada é composta com as camadas abaixo. A opacidade é aplicada depois ao resultado mesclado inteiro. Como altera apenas a composição exibida sem editar pixels, é útil para ajustar cor, adicionar luz ou sombra e sobrepor texturas.

normalDissolveMostra áreas translúcidas como pontos aleatórios. Útil para bordas ásperas e aparência granulada.

oscurecerMultiplyMultiplica as cores para escurecê-las. É o modo de escurecimento mais fácil para line art, sombras, textura de papel e sobreposição de sujeira.

AI efeito camada AI efeito

AI efeito camada é um feature que places.lsfx presets em o tela como camadas, then sends entrada camadas e parâmetros para um ComfyUI Gateway ou NanoBanana Gateway para gerar imagens. isto funciona com o Painel de camadas, Painel de efeitos, e AI efeitos gerenciador separately de o normal ComfyUI e NanoBanana painéis.

básicas flow

  1. de o AI menú, elegir AI efeito Presets... para abrir AI efeitos gerenciador
  2. direita-clique um preset e elegir Adicionar camada AI efeito
  3. em o Painel de camadas, assign entrada camadas para Slot linhas abaixo o AI efeito camada
  4. usar o Painel de efeitos para controle parâmetros, saída destination, e gerar
  5. Aplicar o resultado gerado para o AI efeito própria camada ou para um novo saída camada diretamente acima dela
ItemConteúdo

Preset formato.lsfx. o ZIP contém o manifestoo, Gateway configurações, ícones, e dados relacionados
compatible GatewayComfyUI Gateway / NanoBanana Gateway

Gateways que require externo service access pode ejecutar somente quando externo services são allowed em Preferências e o required API key ou connection configurações são configured.

Formato nativo .lstroke arquivo

.lstroke é um ZIP-baseado nativo formato. em salvar, isto writes para *.lstroke.tmp e então substitui o arquivo de destino. As seguintes informações são salvas:

  • manifestoo JSON (versão e metadados do documento)
  • PNG imagem data para each camada
  • vetorial objeto data
  • página information (v1.1 multipágina)
  • Instantâneo do layout da UI
  • ICC cor profile
