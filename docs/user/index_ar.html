LoomStroke

تطبيق رسم رقمي متكامل لإنتاج المانغا والرسوم التوضيحية

نظرة عامة على التطبيق

LoomStroke تطبيق رسم رقمي يجمع الرسم النقطي ومسارات المتجهات وتحرير النصوص وتعدد الصفحات والملحقات الخارجية وتكامل AI في مساحة إنتاج واحدة. يمكن حفظ ملفات العمل بصيغة.lstroke.

الميزات الرئيسية

  • محرك فرشاة يدعم الضغط والميل
  • طبقة عتامة و مزج وضع إدارة
  • متجه مسارات و معلمية أشكال
  • أفقي و رأسي نص
  • غير إتلافي تأثير طبقات
  • مستندات متعددة الصفحات

AI تكامل

  • ComfyUI سير عمل تكامل
  • NanoBanana (Gemini) صورة توليد
  • محرر المطالبات وإدارة المقتطفات
  • LLM Gateway (OpenAI / Anthropic / Gemini)

شريط الأدوات لوحة

قائمة عمودية لأزرار الأدوات على الحافة اليسرى. يمثّل كل زر مجموعة أدوات؛ ويؤدي الضغط المطوّل لمدة 350 ms إلى فتح قائمة لاختيار متغيرات الأداة.

تخطيط يبدل تلقائياً بين رأسي و أفقي كـ لوحة عرض تغييرات. أيقونة حجم هو 48x48 px.

خصائص الأداة لوحة لوحة

لوحة تعرض إعدادات الأداة النشطة. لها تخطيطان: وضع الشريط أسفل شريط القوائم مباشرة، ووضع اللوحة داخل منطقة الإرساء.

مكوّن

  • إعداد مسبق صف: إعداد مسبق تحديد قائمة مربع + حفظ/حذف أزرار
  • عنصر عنصر مجموعة: حجم, عتامة, صلابة, تباعد, تدفق, و عنصر عنصر أداة إعدادات
  • خصائص الأداة مجموعة: أداة-محدد معلمات
  • الإجراءات عنصر: أداة-محدد إجراء أزرار و عنصر

تلقائي عنصر توليد: عنصر/int -> منزلق, عنصر -> مربع اختيار, عنصر -> قائمة مربع, لون -> لون زر
