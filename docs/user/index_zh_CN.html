LoomStroke

用于漫画和插画制作的一体化数字绘画应用程序

应用概览

LoomStroke 是一款数字绘画应用，可在同一个创作工作区中整合栅格绘画、矢量路径、文本编辑、多页面、外部插件和 AI 联动。工作文件可以保存为.lstroke格式。

主要功能

  • 支持压感和倾斜的笔刷引擎
  • 图层不透明度和混合模式管理
  • 矢量路径和 参数化 形状
  • 横向和纵向文本
  • 非破坏性效果图层
  • 多页面文档

AI 集成

  • ComfyUI 工作流集成
  • NanoBanana (Gemini) 图像生成
  • 提示词编辑器和片段管理
  • LLM Gateway (OpenAI / Anthropic / Gemini)

界面布局

主窗口由以下区域组成。各面板可通过拖放自由排列，也可以合并为标签页。

区域内容
上部菜单栏 + 工具属性栏，用一行显示当前工具设置
左 停靠区工具栏、颜色面板、字体面板和页面面板
居中画布（默认使用基于 QImage 的 SimpleCanvasService）+ 标尺
右 停靠区图层面板、形状管理器、变换、效果和预览
浮动上下文工具栏，在描边后自动显示

Window 可从菜单显示或隐藏各个面板。F11 会切换到全屏模式。

混合模式

图层混合控制所选图层如何与下方图层合成。不透明度会作用于整个混合结果。它只改变显示合成而不编辑像素，因此适合用于颜色调整、添加光影和叠加纹理。

分组模式描述
组仅穿透用于组。 项目 子 图层在 项目 的图层下方， 而不是的 项目 它们 内部 组。
正常正常标准 合成。 上方 图层是 放置 作为-是， 带有不透明度 控制 其 强度。
正常Dissolve将半透明区域显示为随机点状。适合粗糙边缘和颗粒感表现。
变暗变暗优先采用上下图层中较暗的成分。适合在抑制亮部的同时添加阴影和暗部。
变暗正片叠底通过颜色相乘使结果变暗。这是处理线稿、阴影、纸张纹理和污渍叠加时最容易使用的暗化模式。
变暗颜色加深像强烈加深底图一样使其变暗，同时提高饱和度和对比度。适合深阴影和强烈质感。
变暗线性加深通过线性降低亮度来变暗。相比 Color Burn，会产生更强、更偏计算感的暗部。
变暗深色不进行混合，而是从上下图层中选择较暗的颜色。结果接近优先暗色的颜色替换。
变亮变亮优先采用上下图层中较亮的成分。适合在去除暗部的同时添加光和高光。
变亮滤色以 Multiply 的相反方式工作，自然提亮。适合发光、高光、烟雾和光效素材。
变亮颜色减淡变亮 底图 强烈 和创建 鲜明 光。 它可以 裁切 到 白色 容易， so 调整 带有不透明度。
变亮线性减淡(添加)添加 颜色到 项目 强烈。 适合 用于 光 项目， 魔法 效果， 和 强烈 发光。
