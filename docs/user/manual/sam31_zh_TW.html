SAM 3.1 安裝指南

LoomStroke AI Select我們將解釋如何準備SAM 3.1來使用（AI自動選擇）。該過程大約需要 30 分鐘到 1 小時（可能需要更長時間，具體取決於您的網路速度）。

1.SAM 3.1是什麼？

SAM 3.1是Meta發布的影像分割AI。以下函數在 LoomStroke 中使用此功能：

  • AI Select 工具：根據單字和點擊（例如“頭髮”和“人”）建立選擇範圍候選。
  • AI Select Candidates面板：合併並分層找到的候選人。
  • Manga Mask Assistant面板：從漫畫頁面創建框架、氣球和人物等蒙版。

SAM 3.1 與 LoomStroke 主體分離。專用執行環境（作為在您的 PC 內運行的小型伺服器運行）。 LoomStroke上的「設定」按鈕會自動建立此環境，僅下載模型本身（檢查點）並自行放置。有需要。 LoomStroke 不會自動下載模型。

SAM 3.1 不會向外部發送影像並完全在您自己的 PC 內處理它們。您唯一使用網路的時間是下載用於安裝的零件（PyTorch 等）並取得型號。

2.你需要什麼

專案內容
OSWindows 10 / 11（64 bit）
GPU強烈推薦 NVIDIA GPU（相容 CUDA）。在開發測試（RTX 4090）期間，最多使用約 4.6 GB 的 GPU 記憶體來處理一張影像。最好至少有 8 GB GPU 記憶體。
即使沒有GPU，安裝本身也會繼續進行，但最終的運行測試會顯示「CUDA無法使用」的訊息並停止（僅靠CPU將無法達到實際速度）。
英偉達驅動程式新司機。若要設定 PyTorch 的 CUDA 13.0 版本，請使用命令提示字元。 nvidia-smi 執行，右上角「CUDA Version」為 13.0或更高 請確認是這樣。如果缺少，請從 NVIDIA 官方網站更新驅動程式。
PythonPython 3.12或更高版本（3.13 建議）。它必須與 LoomStroke 分開安裝在您的 PC 上（步驟1）。
磁碟空間指南 15 GB 或更多（型號約 3.5 GB + 幾個 GB，例如 PyTorch + 用於工作）。
網際網路僅在安裝過程中需要（PyTorch 有幾個 GB 的下載量）。
Hugging Face帳號需要取得模型（免費）。

3.安裝步驟

步驟1：插入Python 3.12或更高版本

  1. python.org 從下列位置下載 Python 3.13（或 3.12）的 Windows 安裝程式。
  2. 啟動安裝程式並「py launcher」使用包含（Python Launcher）的設定進行安裝。
  3. 在命令提示字元下執行以下命令，Python 3.13.x 如果顯示成這樣就完成了。 
    py -3.13 --version

設定是 py -3.13 → py -3.12 → py -3 → python 搜尋 Python 並使用找到的第一個 3.12 或更高版本。

步驟2 建立SAM 3.1的資料夾

放置模型和執行環境根資料夾我將在有大量可用空間的驅動器上，僅包含半角字母數字字元的路徑建議您使用

例：D:\SAM31

在此資料夾中，您放置了步驟 3 中的模型並設定了執行環境（runtime 資料夾）將自動建立。

第三步：取得模型（檢查點）

SAM 3.1的型號是Hugging Face的型號。 facebook/sam3.1 發佈於本頁訪問需要同意（門禁）是的。

  1. Hugging Face 建立帳戶並登入。
  2. facebook/sam3.1 開啟 ，閱讀使用條款，同意分享您的聯絡人，並要求存取權限。可能需要短暫等待批准。
  3. 批准後，從“文件和版本”選項卡 一組儲存庫文件（sam3.1_multiplex.pt（約 3.5 GB）和 config.json config 檔案）並將其放入步驟 2 中的資料夾中。

如果你熟悉指令，用Hugging Face的官方工具（在瀏覽器中取得存取授權後執行）就可以一次搞定。

py -3.13 -m pip install -U huggingface_hub
hf auth login
hf download facebook/sam3.1 --local-dir D:\SAM31

hf auth login 現在，貼上在 Hugging Face 設定畫面（存取權杖）上建立的讀取令牌。hf 如果找不到該指令，請在安裝 Python 時開啟「將 python.exe 新增至 PATH」並重試，或在瀏覽器中下載。

此模型直接位於根資料夾下或 checkpoints・model 可以將其放置在子資料夾中。檔案名稱是 sam3.1_multiplex.pt 如果是這樣，請使用它，如果它有不同的名稱，請使用 .pt 僅當只有一個文件時使用（如果超過一個則無法確定，將被視為“未找到”）。 LoomStroke 不會複製或移動模型。

步驟 4 允許 LoomStroke 連接到外部服務

設定期間允許通訊下載 PyTorch 等。

  1. 編輯 › 偏好設定（Ctrl+,），打開1選擇“接口”。
  2. 2開啟「允許外部AI服務（ComfyUI、LLM網關、NanoBanana）」。
  3. 3按“應用”儲存。該設定會查看已儲存的設置，因此如果您只是將其打開但不應用它，它將停止在「需要網路權限」。

第 5 步：運行設置

  1. 在首選項左側的清單中 SAM 3.1 選擇。
  2. 1在「瀏覽...」中的「SAM 3.1 根資料夾」中，選擇步驟 2 中的資料夾。3如果狀態「檢查點」中顯示檔案名，則表示已找到該模型。
  3. 4“設定”新聞7進度將顯示在日誌欄位中，接下來的 10 個步驟將按順序進行。
舞台內容大約花費的時間
1.檢查資料夾檢查根資料夾是否存在並且可以寫入，runtime・logs・state 建立一個資料夾。立即
2、Python確認尋找 Python 3.12 或更高版本。立即
3. 創造環境SAM 3.1 專用虛擬環境（runtime\venv）。 LoomStroke主機的環境未被觸及。約1分鐘
4. 準備點準備插入零件的工具（pip）。立即
5、PyTorch介紹如果偵測到NVIDIA GPU，則下載CUDA版本，如果沒有偵測到，則下載並安裝CPU版本PyTorch。幾分鐘到幾十分鐘（幾GB）
6、SAM 3.1介紹插入必要的部分和 SAM 3 程式（GitHub 上的 facebookresearch/sam3）。幾分鐘
7. 檢查型號檢查模型是否位於根資料夾中（不要下載）。立即
8. 運行測試載入模型並檢查是否為SAM 3.1的模型並且可以使用GPU（CUDA）。幾分鐘
9. 啟動worker啟動 SAM 3.1 處理器。幾十秒
10. 回覆確認驗證工作人員的回應是否正確。立即

在日誌的末尾 「SAM 3.1 Ready」如果顯示就完成了。3狀態列將是“Runtime：Ready”、“Checkpoint：sam3.1_ Multiplex.pt”、“Worker：running”，並且還會顯示GPU名稱（CUDA）。OK 關閉首選項。

一路走來失敗4即使按“取消”停止，如果再次按“設定”，跳過已完成的步驟並繼續我會再試一次。你不必重新開始。

步驟6 檢查運轉狀況

  1. 在畫布上和從工具列打開圖像 AI Select （按住所選組的按鈕）。
  2. 您想要在屬性列上的「提示」中尋找的內容（例如hair、person、flower）並按“運行”。
  3. 如果候選人以彩色顯示，則表示成功。按一下“應用”以選擇範圍。

第一次運行將需要一些時間，因為它將模型（大約 3.5 GB）載入到 GPU 上。如果工作執行緒停止，它將在運行時自動啟動。

4. SAM 3.1設定畫面

環境設定 › SAM 3.1 的每一項（編號為步驟5 ）。

專案內容
1SAM 3.1 根資料夾放置模型和執行環境的資料夾（使用「瀏覽...」進行選擇）。
2SAM 3.1 自動啟動伺服器開啟後，worker也會在LoomStroke啟動時啟動（實際使用時才會載入模型）。初始值關閉。即使關閉，執行AI Select時也會自動啟動。
3條件 運行時: 準備好了就準備好了。如果缺少某些內容，將顯示原因代碼（清單）。
檢查站：找到的模型的檔案名稱（如果沒有，則「找不到」）。
勞工：運轉（啟動）/停止（停止）。
模型:loaded（載入到GPU）/unloaded（未載入）。
CUDA：顯示啟動worker時所使用的GPU的名稱。
4設定/取消準備執行環境/中途停止準備。
5啟動/停止/重新啟動手動操縱工人。
6載入模型/卸載模型將模型載入到 GPU 記憶體/從 GPU 記憶體中卸載（工作執行緒保持運行）。
7日誌字段顯示設定和啟動的進度，以及錯誤詳細資訊和解決方案。
8資源快取限制儲存分析結果（掩模等）的上限。 64 至 262144 MB，初始值 2048 MB。

5. 資料夾內容

D:\SAM31\                      ← ルートフォルダー（手順 2）
├ sam3.1_multiplex.pt          ← モデル（手順 3 で自分で置く）
├ config.json ほか              ← モデルの設定ファイル（同上）
├ checkpoints\ / model\        ← （直下に置かない場合のモデルの置き場所）
└ runtime\                     ← セットアップが自動で作成
   ├ venv\                     ← SAM 3.1 専用の Python 環境
   ├ sam3-src\                 ← （任意）オフライン導入用の SAM 3 ソース
   ├ logs\setup.log            ← セットアップのログ
   ├ logs\worker.log           ← ワーカーのログ
   └ state\

6. 處理GPU記憶體

SAM 3.1 將模型載入到 GPU 記憶體中並使用它。如果同時使用ComfyUI等其他GPU，使用完後釋放一些記憶體會更穩定。

AI Select Candidates 面板上的“空閒 SAM 記憶體”從 GPU 記憶體卸載模型。下次使用時會自動重新載入。
首選項 › SAM 3.1 的“卸載模型”與上面相同。
首選項 › “停止”SAM 3.1停止工作執行緒本身（在下次執行時自動啟動）。

7.當事情進展不順利時

如果失敗，則會顯示在日誌欄位中。 [コード] 内容 並將顯示要做什麼。詳細日誌是 ルートフォルダー\runtime\logs\setup.log（設定）和 worker.log（在運行時）。

程式碼意義應付
ROOT_NOT_CONFIGURED根資料夾未設定在首選項 › SAM 3.1 中選擇根資料夾。
ROOT_INVALID沒有資料夾/無法寫入選擇現有的可寫資料夾。
SETUP_REQUIRED還沒有執行環境運行“設定”。
CHECKPOINT_MISSING找不到型號/不是 SAM 3.1 的型號步驟3 根據 sam3.1_multiplex.pt 以及根資料夾中的設定檔。.pt 如果有多個項目，請移動不需要的項目。
PYTHON_UNSUPPORTED未找到 Python 3.12 或更高版本步驟1 並放入 Python （必須從 py 啟動器中找到）。
NETWORK_CONSENT_REQUIRED沒有下載權限步驟4 開啟“允許外部AI服務”適用然後再次設定（訊息顯示“隱私”，但設定位於介面的頁面上）。
VENV_CREATE_FAILED無法創建專用環境檢查可用磁碟空間和資料夾權限，然後重試。
PIP_FAILED無法準備點重新設定一下。
TORCH_INSTALL_FAILEDPyTorch安裝失敗檢查您的網路和 setup.log，然後再試一次。
SAM31_INSTALL_FAILEDSAM 3 主機安裝或操作測試失敗檢查安裝日誌。線下實施第8章。
CUDA_UNAVAILABLE無法使用GPU（CUDA）檢查您的 NVIDIA GPU 和驅動程式。僅 CPU 不足以提供實際速度。
CUDA_MISMATCHPyTorch和驅動CUDA不匹配更新您的 NVIDIA 驅動程序，然後再次嘗試設定。
WORKER_START_FAILED工人沒有啟動檢查worker.log。
HEALTH_FAILED啟動但沒有響應嘗試“重新啟動”，如果不起作用，請檢查worker.log。
MODEL_LOAD_FAILED載入模型失敗檢查worker.log。如果模型檔案已損壞，請重新安裝。
OOMGPU 記憶體不足關閉其他 GPU 密集型應用程序，例如 ComfyUI，或釋放其記憶體並重試。
COMPATIBILITY_UNSUPPORTED不支援安裝的 SAM 3 版本。請等待LoomStroke的更新或向開發者回報。
CANCELLED設定已取消再次按下「設定」即可從上次中斷的位置繼續。

如果在使用具有 AI Select 的工具時收到類似「SAM 3.1 未設定」的訊息，它也對應於上表中的程式碼。環境設定 › 檢查SAM 3.1 的狀態列。

8. 離線安裝/刪除

離線安裝 SAM 3 裝置

GitHub facebookresearch/sam3 一組 (pyproject.toml 資料夾包含） ルートフォルダー\runtime\sam3-src ，SAM 3 主體將從那裡安裝。但是，PyTorch 等零件需要從網路下載。

刪除

  1. 按下首選項 › SAM 3.1 中的「停止」以停止工作器。
  2. 刪除整個根資料夾（專用環境和模型僅在該資料夾中，不會影響LoomStroke本身或其他Python）。
  3. 首選項 › 清除 SAM 3.1 的根資料夾字段，然後按 OK。

請在 Hugging Face facebook/sam3.1 頁面上查看 SAM 3.1 型號的使用條款。
