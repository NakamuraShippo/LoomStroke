SAM 3.1 Installation Guide

LoomStroke AI Select We will explain how to prepare SAM 3.1 to use (automatic selection by AI). The process will take approximately 30 minutes to 1 hour (it may take longer depending on your internet speed).

1. What is SAM 3.1?

SAM 3.1 is an image segmentation AI published by Meta. The following functions use this in LoomStroke:

  • AI Select Tools: Create selection range candidates from words and clicks such as "hair" and "person".
  • AI Select Candidates panel:Combine and layer the found candidates.
  • Manga Mask Assistant panel: Create masks such as frames, balloons, and people from manga pages.

SAM 3.1 is separate from LoomStroke main body.Dedicated execution environment(runs as a small server running inside your PC). The "Setup" button on LoomStroke automatically creates this environment,Download only the model itself (checkpoints) and place it yourself.There is a need. LoomStroke does not automatically download models.

SAM 3.1 does not send images externally and processes them entirely within your own PC. The only times you use the Internet are to download parts for installation (PyTorch, etc.) and to obtain the model.

2. What you need

Item Content
OS Windows 10 / 11（64 bit）
GPU NVIDIA GPU (CUDA compatible) is strongly recommended. During development testing (RTX 4090), a maximum of approximately 4.6 GB of GPU memory was used to process one image. It is best to have at least 8 GB of GPU memory.
Even if there is no GPU, the installation itself will proceed, but the final operation test will display a message that "CUDA cannot be used" and stop (the CPU alone will not be able to achieve practical speed).
NVIDIA driver New driver. To set up the CUDA 13.0 version of PyTorch, use the command prompt. nvidia-smi Execute and "CUDA Version" in the upper right corner is 13.0 or higher Please make sure it is. If it is missing, update the driver from NVIDIA's official website.
Python Python 3.12 or higher(3.13 Recommendation). It must be installed on your PC separately from LoomStroke (Step 1）。
disk space Guideline 15 GB or more(Model approximately 3.5 GB + several GB such as PyTorch + for work).
internet Required only during installation (PyTorch has several GB downloads).
Hugging Face account Required to obtain the model (free).

3. Installation steps

Step 1: Insert Python 3.12 or higher

  1. python.org Download the installer for Windows for Python 3.13 (or 3.12) from.
  2. Start the installer and「py launcher」Install with the settings that include (Python Launcher).
  3. Run the following at a command prompt,Python 3.13.x If it is displayed like this, it is completed. 
    py -3.13 --version

The setup is py -3.13 → py -3.12 → py -3 → python Search for Python and use the first one found for 3.12 or higher.

Step 2 Create a folder for SAM 3.1

Place the model and execution environment root folder I will make On a drive with a lot of free space,Path with only half-width alphanumeric characters It is recommended that you make it with

例：D:\SAM31

In this folder, you placed the model in step 3 and set up the execution environment (runtime folder) will be created automatically.

Step 3: Obtain the model (checkpoint)

The model of SAM 3.1 is the model of Hugging Face. facebook/sam3.1 It is published in This page Consent required for access (gated)It is.

  1. Hugging Face Create an account and log in.
  2. facebook/sam3.1 Open , read the terms of use, agree to share your contacts, and request access. There may be a short wait for approval.
  3. After approval, from the "Files and versions" tab A set of repository files（sam3.1_multiplex.pt(approximately 3.5 GB) and config.json config file) and place it in the folder in step 2.

If you are familiar with the command, you can get it all at once with Hugging Face's official tool (run after receiving access authorization in your browser).

py -3.13 -m pip install -U huggingface_hub
hf auth login
hf download facebook/sam3.1 --local-dir D:\SAM31

hf auth login Now, paste the read token created on the Hugging Face settings screen (Access Tokens).hf If you can't find the command, turn on "Add python.exe to PATH" when installing Python and try again, or download it in your browser.

The model is located directly under the root folder or checkpoints・model It can be placed in a subfolder. The file name is sam3.1_multiplex.pt If so, use that, and if it has a different name, use .pt It is used only when there is only one file (if there is more than one, it cannot be determined and will be treated as "not found"). LoomStroke does not copy or move models.

Step 4 Allow LoomStroke to connect to external services

Allow communication to download PyTorch etc. during setup.

  1. Edit › Preferences（Ctrl+,), open 1 Select "Interface".
  2. 2 Turn on "Allow external AI services (ComfyUI, LLM Gateway, NanoBanana)".
  3. 3 Press "Apply" to save.The setup looks at saved settings, so if you just turn it on but don't apply it, it will stop at "Network permission required".

  1. In the list on the left of the Preferences SAM 3.1 Choose.
  2. 1 In "Browse..." for "SAM 3.1 Root Folder", select the folder in step 2.3 If the file name is displayed in the status "checkpoint", the model has been found.
  3. 4"Setup"Press 7 The progress will be displayed in the log field, and the next 10 steps will proceed in order.

Step 6 Check the operation

  1. Open the image on canvas and from the toolbar AI Select (Press and hold the button of the selected group).
  2. What you want to look for in "Prompt" on the property bar (e.g.hair、person、flower) and press "Run".
  3. If the candidate is displayed in color, it is a success. Click “Apply” to select the range.

The first run will take some time as it loads the model (approximately 3.5 GB) onto the GPU. If the worker is stopped, it will be automatically started at runtime.

6. Handling GPU memory

SAM 3.1 loads the model into GPU memory and uses it. If you are working with other GPUs such as ComfyUI at the same time, it will be more stable if you free up some memory when you are finished using it.

"Free SAM memory" on AI Select Candidates panel Unload the model from GPU memory. It will be automatically reloaded the next time you use it.
Preferences › “Unload Model” for SAM 3.1 Same as above.
Preferences › “Stop” SAM 3.1 Stops the worker itself (starts automatically on next run).

7. When things don't go well

If it fails, it will be displayed in the log field. [コード] 内容 and what to do will be displayed. Detailed log is ルートフォルダー\runtime\logs\setup.log(setup) and worker.log(at runtime).

code meaning Coping
ROOT_NOT_CONFIGURED Root folder not set Select the root folder in Preferences › SAM 3.1.
ROOT_INVALID There is no folder/cannot write to it Select an existing writable folder.
SETUP_REQUIRED No execution environment yet Run "Setup".
CHECKPOINT_MISSING Model not found/Not a model for SAM 3.1 Step 3 as per sam3.1_multiplex.pt and the configuration file in the root folder..pt If there are multiple items, move the unnecessary ones.
PYTHON_UNSUPPORTED Python 3.12 or higher not found Step 1 and put in Python (must be found from py launcher).
NETWORK_CONSENT_REQUIRED No download permission Step 4 Turn on "Allow external AI services" in Applicable and then set it up again (the message says "Privacy", but the settings are on a page in the interface).
VENV_CREATE_FAILED Unable to create a dedicated environment Check free disk space and folder permissions and try again.
PIP_FAILED Unable to prepare pip Set it up again.
TORCH_INSTALL_FAILED Installation of PyTorch failed Check your network and setup.log and try again.
SAM31_INSTALL_FAILED SAM 3 main unit installation or operation test failed Check setup.log. Offline implementation Chapter 8。
CUDA_UNAVAILABLE GPU (CUDA) cannot be used Check your NVIDIA GPU and drivers. The CPU alone is not enough to provide practical speed.
CUDA_MISMATCH PyTorch and driver CUDA do not match Update your NVIDIA drivers, then try setup again.
WORKER_START_FAILED worker doesn't start Check worker.log.
HEALTH_FAILED Starts but does not respond Try "restart" and if that doesn't work, check worker.log.
MODEL_LOAD_FAILED Failed to load model Check worker.log. If the model file is corrupted, reinstall it.
OOM Out of GPU memory Close other GPU-intensive apps, such as ComfyUI, or free up their memory and try again.
COMPATIBILITY_UNSUPPORTED The version of SAM 3 that was installed is not supported.Please wait for the update of LoomStroke or report it to the developer.
CANCELLED Setup was canceled Press "Setup" again to resume from where you left off.

If you get a message like "SAM 3.1 is not set up" when using a tool with AI Select, it also corresponds to the code in the table above. Environment Settings › Check the status column of SAM 3.1.

8. Offline installation/deletion

Installing the SAM 3 unit offline

GitHub facebookresearch/sam3 A set of (pyproject.toml folder containing) ルートフォルダー\runtime\sam3-src , the SAM 3 body will be installed from there. However, parts such as PyTorch require downloading from the network.

delete

  1. Press "Stop" in Preferences › SAM 3.1 to stop the worker.
  2. Delete the entire root folder (the dedicated environment and model are only in this folder, and will not affect the LoomStroke itself or other Pythons).
  3. Preferences › Clear the root folder field for SAM 3.1 and press OK.

Please check the terms of use for the SAM 3.1 model on the Hugging Face facebook/sam3.1 page.
