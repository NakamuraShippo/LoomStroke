SAM 3.1 প্রবেশ নির্দেশিকা

LoomStroke এর AI Select আমরা SAM 3.1 ব্যবহারের জন্য প্রস্তুত করার পদ্ধতি ব্যাখ্যা করব। প্রক্রিয়াটি প্রায় 30 মিনিট থেকে 1 ঘন্টা নিতে পারে (আপনার ইন্টারনেট স্পিডের উপর নির্ভর করে এটি আরও দীর্ঘ হতে পারে)।

1. SAM 3.1 কি?

SAM 3.1 হল মেটা দ্বারা প্রকাশিত একটি ইমেজ সেগমেন্টেশন AI। নিম্নলিখিত ফাংশনগুলি LoomStroke-এ এটিকে ব্যবহার করে:

  • AI Select টুল: Creates candidate selections for the selected range by typing words such as 'hair' or 'person' or by clicking.
  • AI Select Candidates প্যানেল: পাওয়া গেল প্রস্তাবের সংযোজন এবং লেয়ার করা।
  • Manga Mask Assistant প্যানেল：ম্যানুয়াল পেজ থেকে কমা, ফুকিদাশি, মানুষ ইত্যাদির মাস্ক একত্রে তৈরি করুন।

SAM 3.1 হলো LoomStroke এর মূল প্রোগ্রামের বাইরে একটি আলাদা,স্পেশাল রান পরিবেশ(আপনার পিসির ভিতরে একটি ছোট সার্ভার চালানো হয়)। LoomStroke-এর "সেটআপ" বাটনটি এই পরিবেশটি স্বয়ংক্রিয়ভাবে তৈরি করে।মডেলের মূল (চেকপয়েন্ট) নিজের দিয়ে ডাউনলোড করে রাখুন প্রয়োজন আছে। LoomStroke মডেলগুলি স্বয়ংক্রিয়ভাবে ডাউনলোড করে না।

SAM 3.1 আপনার নিজের প্যাস এর মধ্যে ইমেজ পাঠায় না এবং এটি আপনার কম্পিউটারে পূর্ণ প্রক্রিয়া করে। আপনি ইন্টারনেট ব্যবহার করেন শুধুমাত্র ইনস্টলেশনের জন্য (PyTorch ইত্যাদি) এবং মডেল পাওয়ার জন্য।

2. প্রয়োজনীয় বিষয়

প্রবেশ সামগ্রী
OS Windows 10 / 11（64 bit）
GPU NVIDIA প্রস্তাবিত GPU (CUDA সমর্থন) অত্যন্ত প্রতিশ্রুতি দেয়. উন্নয়ন পরীক্ষার সময় (RTX 4090) একটি চিত্র প্রসেস করার জন্য প্রায় 4.6 জিবি গ্যাপ মেমরি ব্যবহার করা হয়েছিল। এর জন্য কমপক্ষে 8 জিবি গ্যাপ মেমরি থাকা উচিত।
GPU না থাকলেও ইনস্টলেশন প্রক্রিয়া চলবে, কিন্তু শেষ অপারেশন পরীক্ষায় একটি সন্দেহ দেখাবে যে "CUDA ব্যবহার করা যাবে না" এবং বন্ধ হয় (মাত্র সিপিইউ প্রায় ব্যবহারযোগ্য হবে না)।
NVIDIA ড্রাইভার নতুন ড্রাইভার। CUDA 13.0 এর পাইটর সংস্করণ সেট করার জন্য কমান্ড প্রম্পট ব্যবহার করুন। nvidia-smi করে ডান উপরের 'CUDA Version' যা 13.0 এর চেয়ে বেশি আপনি নিশ্চিত হতে হবে। যদি এটি অনুপস্থিত হয়, তবে আপনার নভেল ওয়েবসাইট থেকে ড্রাইভার আপডেট করুন।
Python Python 3.12 এর উপর（3.13 প্রতিশ্রুতি করা হয়েছে）。LoomStroke এর বাইরে কম্পিউটারে স্থানান্তরিত হওয়া দরকার (স্টেপ 1）。
ডিস্কের খালি জায়গাসীমা 15 GB এর বেশি（মডেল প্রায় 3.5 GB + PyTorch ইত্যাদি কয়েক GB + কাজের জন্য）。
ইন্টারনেট প্রবেশের সময় প্রয়োজন (PyTorch এর মধ্যে কিছু জায়গা ডাউনলোড হবে)।
Hugging Face অ্যাকাউন্ট মডেল পাওয়ার জন্য প্রয়োজন (মুক্ত)।

3. গাইড প্রক্রিয়া

স্টেপ 1: Python 3.12 এর উপরে ইনস্টল করুন

  1. python.org পাইথন 3.13 (অথবা 3.12) এর জন্য ওয়ার্ড প্রোগ্রামের ইনস্টলার ডাউনলোড করুন এখন থেকে।
  2. ইনস্টলার চালানো এবং「py launcher」（Python ল্যান্চার） যে সেটিং থাকবে তা সেই অবস্থায় ইনস্টল করুন।
  3. কমান্ড প্রম্পটে নিচের কাজ করুন এবংPython 3.13.x এভাবে প্রদর্শিত হলে সম্পূর্ণ হয়ে যাবে। 
    py -3.13 --version

সেটআপ হবে py -3.13 → py -3.12 → py -3 → python প্রতিটি অনুসারে পাইথন খুঁজে পাবে, যেখানে 3.12 এর উপরের প্রথমটি ব্যবহার হবে।

স্টেপ 2: SAM 3.1 এর জন্য ফোল্ডার তৈরি করুন

মডেল এবং রান পরিবেশ রাখুন রুট ফোল্ডার তৈরি করা হবে। বেশি ফাইল স্পেস রাখা দ্রুত ড্রাইভে,শুধুমাত্র হালকা অক্ষর ও সংখ্যা বিশিষ্ট পাথ সেখানে তৈরি করা উচিত।

例：D:\SAM31

এই ফোল্ডারে, ধাপ 3 এ মডেল রাখুন এবং ধাপ 5 এর সেটআপে রান করার জন্য পরিবেশ (runtime ফোল্ডার) স্বয়ংক্রিয়ভাবে তৈরি হয়।

স্টেপ 3: মডেল (চেকপয়েন্ট) পাওয়া যায়

SAM 3.1 এর মডেলগুলি হলো Hugging Face এর facebook/sam3.1 এখানে প্রকাশিত হয়েছে। এই পৃষ্ঠটি হল অনুমতি প্রয়োজন (গেট সহ)হয়।

  1. Hugging Face একটি অ্যাকাউন্ট তৈরি করে লগইন করুন।
  2. facebook/sam3.1 থাম্ব খুলুন, ব্যবহারের শর্তগুলি পড়ুন, আপনার যোগাযোগ শেয়ার করার সম্মতি দিন এবং অ্যাক্সেস চান। অনুমতির জন্য কিছু সময় প্রয়োজন হতে পারে।
  3. অনুমোদন পাওয়ার পর 'Files and versions' ট্যাব থেকে রিপোজিটরির ফাইল সমস্ত（sam3.1_multiplex.pt(প্রায় 3.5 GB) এবং config.json যেমন সেটিংস ফাইলগুলি) ডাউনলোড করে পদক্ষেপ 2 এর ফোল্ডারে রাখুন।

আপনি যদি কমান্ডের সাথে পরিচিত হন, তবে আপনি হাউজিং ফেসের অফিসিয়াল টুল দিয়ে সবকিছু একসাথে পাবেন (ব্রাউজারে অ্যাকেস অথোরাইজেশন পেয়ে পরে চালানো হবে)।

py -3.13 -m pip install -U huggingface_hub
hf auth login
hf download facebook/sam3.1 --local-dir D:\SAM31

hf auth login এখন, হিউগ ফেসের সেটিংস স্ক্রিনে তৈরি করা হওয়া রিড টোকেন কপি করুন (অ্যাকেস টোকেন)।hf কমান্ড খুঁজে পাওয়া যাচ্ছে না? পাইথন ইনস্টল করার সময় 'Add python.exe to PATH' অবস্থায় সক্রিয় করে আবার চেষ্টা করুন, বা ব্রাউজারে ডাউনলোড করুন।

মডেলটি রুট ফোল্ডারের নিচে বা checkpoints・model সাব ফোল্ডারে রাখা যেতে পারে। ফাইলের নাম যদি sam3.1_multiplex.pt যদি তা ব্যবহার করা যায়, অন্য নামে হলে .pt এটি এমন ক্ষেত্রে ব্যবহার করা হয় যখন একটি ফাইল থাকে (যদি একাধিক থাকে, তবে এটি নির্ধারণ করা যায় না এবং "নাই ফাইন্ড" হিসাবে দেখানো হবে)। LoomStroke মডেলগুলি কপি করে না বা স্থানান্তর করে না।

স্টেপ 4: LoomStroke এ বাইরের সার্ভিসের সংযোগ অনুমতি দিন

সেটআপের সময় PyTorch এর মতো কিছু ডাউনলোড করার জন্য কমিউনিকেশন অনুমতি দিন।

  1. সম্পাদনা › সেটিংস（Ctrl+,) খুলুন,1« ইন্টারফেস » নির্বাচন করুন।
  2. 2"বাইরের AI সেবা (ComfyUI, LLM Gateway, NanoBanana) অনুমতি দিন" অনুমতি দিন।
  3. 3 সংরক্ষণের জন্য 'প্রয়োগ' ক্লিক করুন।সেটআপ সংরক্ষিত সেটিংস দেখে, তাই যদি আপনি শুধুমাত্র চালু করেন কিন্তু তা প্রয়োগ করেন না, তবে এটি "নেটওয়ার্ক অনুমতি প্রয়োজন" এ থাকবে।

স্টেপ 5: সেটআপ করুন

  1. প্রতি প্রতিক্রিয়ার বাম পাশের লিস্টে SAM 3.1 সেট করা হবে।
  2. 1"SAM 3.1 Root Folder" এর জন্য "Browse..." এ স্টেপ 2 এর ফোল্ডারটি নির্বাচন করুন।3 স্টেটে 'চেকপয়েন্ট' এ ফাইলের নাম দেখা যায় তবে মডেল পাওয়া হয়েছে।
  3. 4« সেটআপ »প্রেস করুন।7 লগ স্পেসে প্রগতি প্রবাহিত হয় এবং পরবর্তী 10 পর্যায় স্বাভাবিকভাবে প্রবাহিত হয়।
স্তর সামগ্রীসময়ের অনুমান
1. ফোল্ডার পরিবেশন রুট ফোল্ডার থাকা এবং লিখে দেওয়া যায় কিনা নিশ্চিত করুন, এবংruntime・logs・state ফোল্ডার তৈরি করবে।ব্রেক
2. Python পরিষ্কার করুন পাইথন 3.12 এর উপরে খুঁজে বের করা হবে।ব্রেক
3. পরিবেশের তৈরিSAM 3.1 এর জন্য ভাবিত পরিবেশ (runtime\venv) তৈরি করা হবে। LoomStroke মূল পরিবেশে প্রবেশ করবে না।1 মিনিট পর্যন্ত
4. pip প্রস্তুত করাপার্ট যোগ করার উপকরণ (pip) প্রস্তুত করা হবে।ব্রেক
5. PyTorch এর প্রবেশ NVIDIA GPU অনুসন্ধান করা হলে CUDA সংস্করণটি ডাউনলোড করুন, না হলে CPU সংস্করণের PyTorch ডাউনলোড করে ইনস্টল করুন।কয়েক মিনিট থেকে কয়েক দশক মিনিট（কয়েক জিবি）
6. SAM 3.1 এর প্রবেশ প্রয়োজনীয় অংশ এবং SAM 3 প্রোগ্রাম (facebookresearch/sam3 গিটহাবে) যোগ করুন।কয়েক মিনিট
7. মডেলের যাচাই মডেল রুট ফোল্ডারে থাকছে কিনা চেক করুন (ডাউনলোড করবে না)।ব্রেক
8. কাজের পরীক্ষামডেল লোড করুন এবং যাচাই করুন যে এটি SAM 3.1 এর মডেল এবং GPU (CUDA) ব্যবহার করা যায়।কয়েক মিনিট
9. ওয়ারকার স্টার্ট করাSAM 3.1 এর প্রক্রিয়াকারী (ওয়ারকার) চালু করুন।কয়েক সেকেন্ড
10. প্রতিক্রিয়া যাচাই ওয়ারকার যথাযথভাবে প্রতিক্রিয়া দেয় কিনা তা যাচাই করুন।ব্রেক

লগের শেষে 「SAM 3.1 Ready」এটি দেখা গেলে সম্পূর্ণ হয়ে যাবে।3 স্ট্যাটাস কলামে অবস্থা হবে "Runtime: Ready", "Checkpoint: sam3.1_multiplex.pt", "Worker: running", এবং GPU নাম (CUDA) এর প্রদর্শন হবে।OK সেটিংস বন্ধ করে দিন।

অনেক সময় ব্যর্থ হয় বা4 ক্যানসেল করা হলেও আবার সেটআপ ক্লিক করলে হবে,সম্পূর্ণ হওয়া অংশগুলি স্কিপ করে পরবর্তী অংশ থেকে শুরু করুন আবার শুরু করুন। প্রথম থেকে শুরু করা হবে না।

ধাপ 6: কাজ পরীক্ষা করুন

  1. ক্যানভাসে ইমেজ খুলুন এবং টুলবার থেকে AI Select সেট করুন (সিলেকশন গ্রুপ বাটনে দীর্ঘ চাপুন)।
  2. প্রপার্টি বারের 'Prompt' এ খুঁজবে যা খুঁজছে (যেমন:hair、person、flower)
  3. যদি প্রস্তাব রঙে দেখায় তবে সফল হয়। 'Apply' দিয়ে সিলেকশন অংশ হবে।

প্রথম চালানো অনেক সময় নেবে কারণ মডেল (প্রায় 3.5 GB) গ্যাপ এর উপরে লোড হবে। যদি কাজটি বন্ধ করা হয়, তবে চালানোর সময় স্বয়ংক্রিয়ভাবে শুরু হবে।

4. SAM 3.1 সেটিংস পেজ

পরিবেশ সেটিং › SAM 3.1 এর প্রতিটি প্যারামিটার (সংখ্যা হল স্টেপ 5 যে ছবির জন্য সামর্থ্য রয়েছে)।

প্রবেশ সামগ্রী
1 SAM 3.1 মূল ফোল্ডার মডেল এবং রান পরিবেশ রাখার ফোল্ডার (সংযোগ করুন... দিয়ে নির্বাচন করুন)।
2 SAM 3.1 সার্ভার স্বয়ংক্রিয়ভাবে শুরু করুন সক্রিয় হলে, লুমস্ট্রোক শুরু হওয়ার সাথে সাথে কাজটি শুরু হবে (মডেলটি কাজের সময় পর্যন্ত লোড হবে না)। প্রারম্ভিক মান অক্ষম। যদিও এটি অক্ষম হয়, তবুও এই কাজটি করা হয় যখন AI Select করা হয়।
3 স্থিতি রাউন্টাইম：সংস্থাপন সম্পন্ন হলে Ready। যদি কোন কিছু অনুপস্থিত থাকে তবে কারণের কোড দেখানো হবে (সম্পূর্ণ তালিকা）。
চেকপয়েন্টঃ আবিষ্কৃত মডেলের ফাইলের নাম (না থাকলে 'অনুসন্ধান করা হয়নি')।
কাজকর্তাঃ running (চালানো হচ্ছে) / stopped (স্টপ হয়েছে)।
মডেল： লোড করা (GPU এ লোড করা হয়েছে) / লোড না করা (লোড না করা হয়েছে)।
CUDAঃ ওয়ার্কার শুরু হওয়ার সময়, ব্যবহার করা GPU এর নাম দেখাবে।
4 সেট আপ / ক্যানসেল রান পরিবেশ প্রস্তুত করা / অর্ধেক বন্ধ করা
5 স্টার্ট / স্টপ / রিস্টার্ট কাজকারীকে হাতে কাজ করুন।
6 মডেল লোড / মডেল অ্যানলোড মডেল গ্যাপ মেমরি তে লোড করুন/গ্যাপ মেমরি থেকে অ্যান্ড করুন (ওয়ার্কারগুলি চলছে)।
7 লগ সেকশন সেটআপ এবং শুরুর প্রক্রিয়া, ত্রুটির বিষয় এবং সমাধান প্রদর্শন করে।
8 অ্যাসেট কেশ সীমাবিশ্লেষণের ফলাফল (মাস্ক ইত্যাদি) সংরক্ষণের উপরিস্থান। 64 থেকে 262144 MB, প্রারম্ভিক মান 2048 MB।

6. GPU মেমোরির ব্যবহার

SAM 3.1 মডেলটি GPU মেমোরি এ লোড করে এবং এটি ব্যবহার করে। যদি আপনি অন্য কোনও GPU এর সাথে কাজ করেন যেমন ComfyUI, তবে এটি বেশি স্থায়ী হবে যদি আপনি এটি ব্যবহার শেষ করে কিছু মেমোরি মুক্ত করেন।

AI Select Candidates প্যানেলের 'SAM মেমরি মুক্ত করুন'মডেলটি GPU মেমোরি থেকে নিচ্ছে। পরবর্তী ব্যবহারে স্বয়ংক্রিয়ভাবে পুনরায় লোড করা হবে।
পরিবেশ সেটিংস › SAM 3.1 এর 'মডেল ডিসলোড'সেই স্থানে।
এনভায়রনমেন্ট সেটিংস › SAM 3.1 এর 'স্টপ'ওয়ারকার নিজেকে বন্ধ করুন (পরবর্তী চালানোর সময় স্বয়ংক্রিয়ভাবে চালু হবে)।

7. কাজ হয়না হলে

ব্যর্থ হলে লগ স্থানে [コード] 内容 এবং সমাধানের উপায় দেখানো হবে। বিস্তারিত লগ হবে ルートフォルダー\runtime\logs\setup.log（সেটআপ） এবং worker.log(রান করার সময়) থাকে।

কোড অর্থ সমাধান
ROOT_NOT_CONFIGURED রুট ফোল্ডার নির্ধারিত না হয়েছেপরিবেশ সেটিংস › SAM 3.1 এ রুট ফোল্ডার নির্বাচন করুন।
ROOT_INVALID ফোল্ডার নেই / লিখা যায় নাপ্রায় আছে এবং লেখা যোগ্য ফোল্ডার নির্বাচন করুন।
SETUP_REQUIRED অবস্থান অবস্থা আবেদন করা হয়নিসেটআপ চালান।
CHECKPOINT_MISSING মডেল খুঁজে পাওয়া যায়না / SAM 3.1 এর জন্য মডেল নয়স্টেপ 3 সেই পদ্ধতির মতো sam3.1_multiplex.pt এবং সেটিং ফাইলগুলি রুট ফোল্ডারে রাখুন।.pt যদি বহু থাকে তবে অপ্রয়োজনীয়গুলি সরানো হবে।
PYTHON_UNSUPPORTED পাইথন 3.12 এর উপরে পাওয়া যায় নাস্টেপ 1 পাইথন যোগ করা হয় (py launcher থেকে খুঁজে পাওয়া হবে প্রয়োজন)।
NETWORK_CONSENT_REQUIRED ডাউনলোডের অনুমতি নেই স্টেপ 4 যেখানে 'বাইরের AI সার্ভিস অনুমতি' অন করেপ্রয়োগ করুন এবং তারপর আবার সেট করুন (সন্দেহ হলে "Privacy" বলে আছে কিন্তু সেটিংস ইন্টারফেসের একটি পেজে আছে)।
VENV_CREATE_FAILED স্পেশাল পরিবেশ তৈরি করা যাবে নাডিস্কের খালি জায়গা এবং ফোল্ডারের অধিকার নিশ্চিত করে আবার চালান।
PIP_FAILED পিপ প্রস্তুত করা যায় নাআবার সেট আপ করুন।
TORCH_INSTALL_FAILED PyTorch এর প্রবেশে ব্যর্থতানেটওয়ার্ক এবং setup.log নিশ্চিত করে আবার চালান।
SAM31_INSTALL_FAILED SAM 3 এর প্রবেশ বা কাজের পরীক্ষা ব্যর্থ setup.log দেখুন। অফলাইন প্রবেশ হল 8 অধ্যায়。
CUDA_UNAVAILABLE GPU (CUDA) ব্যবহার করা যাবে নাআপনার NVIDIA GPU এবং ড্রাইভারগুলি চেক করুন। কেবল CPU একটি প্রাকৃতিক গতি দেয় না।
CUDA_MISMATCH PyTorch এবং CUDA ড্রাইভার একত্রে কাজ করে নাUpdate the NVIDIA driver and then run the setup again.
WORKER_START_FAILED ওয়ারকার স্টার্ট হয় নাworker.log দেখুন।
HEALTH_FAILED স্টার্ট হয়েছে কিন্তু প্রতিক্রিয়া নেই পুনরায় চালানো চেষ্টা করুন, যদি কাজ না হয় তবে worker.log চেক করুন।
MODEL_LOAD_FAILED মডেল লোড হয় নাworker.log চেক করুন। মডেল ফাইল ভাঙা হলে পুনরায় নিয়ে আসুন।
OOM GPU মেমোরি অপর্যাপ্ত অন্যান্য GPU ব্যবহার করে অ্যাপস (যেমন ComfyUI) বন্ধ করুন বা তাদের মেমরি মুক্ত করে আবার চেষ্টা করুন।
COMPATIBILITY_UNSUPPORTED যোগ করা SAM 3 এর সংস্করণটি অসম্পূর্ণ LoomStroke এর আপডেট অপেক্ষা করুন বা উন্নয়কদের কাছে রিপোর্ট করুন।
CANCELLED সেটআপ বন্ধ করা হয়আবার 'সেটআপ' ক্লিক করলে পরবর্তী অংশ থেকে আবার শুরু হবে।

যদি আপনি AI Select ব্যবহার করার সময় 'SAM 3.1 সেট আপ হয়নি' এর মতো একটি মেসেজ পান, তবে এটি উপরের তালিকার কোডের সাথেও সংযুক্ত। পরিবেশ সেটিংস › SAM 3.1 এর অবস্থার কলামটি চেক করুন।

8. অফলাইন প্রবেশ ও মুছে ফেলা

SAM 3 এর অফলাইন প্রবেশ

GitHub এর facebookresearch/sam3 এক সম্পূর্ণ সংস্করণ (pyproject.toml যা ফোল্ডারে রয়েছে তার মধ্যে) কে ルートフォルダー\runtime\sam3-src ", SAM 3 এর শরীরটি সেখান থেকে ইনস্টল হবে। তবে পার্টস যেমন PyTorch নেটওয়ার্ক থেকে ডাউনলোড করা হবে।"

হারিয়ে ফেলা

  1. Environment Settings › In SAM 3.1, press 'Stop' to stop the worker.
  2. সমস্ত রুট ফোল্ডার মুছে ফেলুন (স্পেশাল পরিবেশ এবং মডেল এই ফোল্ডারে রয়েছে, এবং লুম স্ট্রোক এবং অন্যান্য পাইথনের প্রভাব না দেবে)।
  3. পরিবেশ সেট আপ › SAM 3.1 এর রুট ফোল্ডার ফিল্ড খালি করে OK বাটন দেখান।

SAM 3.1 মডেলের ব্যবহারের শর্তগুলি চেক করুন হুজিং ফেসবুক/সাম3.1 পেজে।
