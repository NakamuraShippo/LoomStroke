SAM 3.1 安装指南

LoomStroke AI Select我们将解释如何准备SAM 3.1来使用（AI自动选择）。该过程大约需要 30 分钟到 1 小时（可能需要更长时间，具体取决于您的互联网速度）。

1.SAM 3.1是什么？

SAM 3.1是Meta发布的图像分割AI。以下函数在 LoomStroke 中使用此功能：

  • AI Select 工具：根据单词和点击（例如“头发”和“人”）创建选择范围候选。
  • AI Select Candidates面板：合并并分层找到的候选者。
  • Manga Mask Assistant面板：从漫画页面创建框架、气球和人物等蒙版。

SAM 3.1 与 LoomStroke 主体分离。专用执行环境（作为在您的 PC 内运行的小型服务器运行）。 LoomStroke上的“设置”按钮会自动创建此环境，仅下载模型本身（检查点）并自行放置。有需要。 LoomStroke 不会自动下载模型。

SAM 3.1 不向外部发送图像并完全在您自己的 PC 内处理它们。您唯一使用互联网的时间是下载用于安装的部件（PyTorch 等）并获取型号。

2.你需要什么

项目内容
OSWindows 10 / 11（64 bit）
GPU强烈推荐 NVIDIA GPU（兼容 CUDA）。在开发测试（RTX 4090）期间，最多使用约 4.6 GB 的 GPU 内存来处理一张图像。最好至少有 8 GB GPU 内存。
即使没有GPU，安装本身也会继续进行，但最终的运行测试会显示“CUDA无法使用”的消息并停止（仅靠CPU将无法达到实际速度）。
英伟达驱动程序新司机。要设置 PyTorch 的 CUDA 13.0 版本，请使用命令提示符。 nvidia-smi 执行，右上角“CUDA Version”为 13.0或更高 请确认是这样。如果缺少，请从 NVIDIA 官方网站更新驱动程序。
PythonPython 3.12或更高版本（3.13 建议）。它必须与 LoomStroke 分开安装在您的 PC 上（步骤1）。
磁盘空间指南 15 GB 或更多（型号大约 3.5 GB + 几个 GB，例如 PyTorch + 用于工作）。
互联网仅在安装过程中需要（PyTorch 有几个 GB 的下载量）。
Hugging Face帐号需要获取模型（免费）。

3、安装步骤

步骤1：插入Python 3.12或更高版本

  1. python.org 从以下位置下载 Python 3.13（或 3.12）的 Windows 安装程序。
  2. 启动安装程序并「py launcher」使用包含（Python Launcher）的设置进行安装。
  3. 在命令提示符下运行以下命令，Python 3.13.x 如果显示成这样就完成了。 
    py -3.13 --version

设置是 py -3.13 → py -3.12 → py -3 → python 搜索 Python 并使用找到的第一个 3.12 或更高版本。

步骤2 创建SAM 3.1的文件夹

放置模型和执行环境根文件夹我将在有大量可用空间的驱动器上，仅包含半角字母数字字符的路径建议您使用

例：D:\SAM31

在此文件夹中，您放置了步骤 3 中的模型并设置了执行环境（runtime 文件夹）将自动创建。

第三步：获取模型（检查点）

SAM 3.1的型号是Hugging Face的型号。 facebook/sam3.1 发布于本页访问需要同意（门禁）是的。

  1. Hugging Face 创建帐户并登录。
  2. facebook/sam3.1 打开 ，阅读使用条款，同意共享您的联系人，并请求访问权限。可能需要短暂等待批准。
  3. 批准后，从“文件和版本”选项卡 一组存储库文件（sam3.1_multiplex.pt（约 3.5 GB）和 config.json config 文件）并将其放入步骤 2 中的文件夹中。

如果你熟悉命令，用Hugging Face的官方工具（在浏览器中获得访问授权后运行）就可以一次性搞定。

py -3.13 -m pip install -U huggingface_hub
hf auth login
hf download facebook/sam3.1 --local-dir D:\SAM31

hf auth login 现在，粘贴在 Hugging Face 设置屏幕（访问令牌）上创建的读取令牌。hf 如果找不到该命令，请在安装 Python 时打开“将 python.exe 添加到 PATH”并重试，或者在浏览器中下载。

该模型直接位于根文件夹下或 checkpoints・model 可以将其放置在子文件夹中。文件名是 sam3.1_multiplex.pt 如果是这样，请使用它，如果它有不同的名称，请使用 .pt 仅当只有一个文件时使用（如果超过一个则无法确定，将被视为“未找到”）。 LoomStroke 不复制或移动模型。

步骤 4 允许 LoomStroke 连接到外部服务

设置期间允许通信下载 PyTorch 等。

  1. 编辑 › 偏好设置（Ctrl+,），打开1选择“接口”。
  2. 2开启“允许外部AI服务（ComfyUI、LLM网关、NanoBanana）”。
  3. 3按“应用”保存。该设置会查看保存的设置，因此如果您只是将其打开但不应用它，它将停止在“需要网络权限”。

第 5 步：运行设置

  1. 在首选项左侧的列表中 SAM 3.1 选择。
  2. 1在“浏览...”中的“SAM 3.1 根文件夹”中，选择步骤 2 中的文件夹。3如果状态“检查点”中显示文件名，则表明已找到该模型。
  3. 4“设置”新闻7进度将显示在日志字段中，接下来的 10 个步骤将按顺序进行。
舞台内容大约花费的时间
1.检查文件夹检查根文件夹是否存在并且可以写入，runtime・logs・state 创建一个文件夹。立即
2、Python确认寻找 Python 3.12 或更高版本。立即
3. 创造环境SAM 3.1 专用虚拟环境（runtime\venv）。 LoomStroke主机的环境未被触及。约1分钟
4. 准备点准备插入零件的工具（pip）。立即
5、PyTorch介绍如果检测到NVIDIA GPU，则下载CUDA版本，如果没有检测到，则下载并安装CPU版本PyTorch。几分钟到几十分钟（几GB）
6、SAM 3.1介绍插入必要的部分和 SAM 3 程序（GitHub 上的 facebookresearch/sam3）。几分钟
7. 检查型号检查模型是否位于根文件夹中（不要下载）。立即
8. 运行测试加载模型并检查是否是SAM 3.1的模型并且可以使用GPU（CUDA）。几分钟
9. 启动worker启动 SAM 3.1 处理器。几十秒
10. 回复确认验证工作人员的响应是否正确。立即

在日志的末尾 「SAM 3.1 Ready」如果显示就完成了。3状态栏将是“Runtime：Ready”、“Checkpoint：sam3.1_ Multiplex.pt”、“Worker：running”，并且还会显示GPU名称（CUDA）。OK 关闭首选项。

一路走来失败4即使按“取消”停止，如果再次按“设置”，跳过已完成的步骤并继续我会再试一次。你不必重新开始。

步骤6 检查运行情况

  1. 在画布上和从工具栏中打开图像 AI Select （按住所选组的按钮）。
  2. 您想要在属性栏上的“提示”中查找的内容（例如hair、person、flower）并按“运行”。
  3. 如果候选人以彩色显示，则表示成功。单击“应用”以选择范围。

第一次运行将需要一些时间，因为它将模型（大约 3.5 GB）加载到 GPU 上。如果工作线程停止，它将在运行时自动启动。

5. 文件夹内容

D:\SAM31\                      ← ルートフォルダー（手順 2）
├ sam3.1_multiplex.pt          ← モデル（手順 3 で自分で置く）
├ config.json ほか              ← モデルの設定ファイル（同上）
├ checkpoints\ / model\        ← （直下に置かない場合のモデルの置き場所）
└ runtime\                     ← セットアップが自動で作成

   ├ sam3-src\                 ← （任意）オフライン導入用の SAM 3 ソース
   ├ logs\setup.log            ← セットアップのログ
   ├ logs\worker.log           ← ワーカーのログ
   └ state\

6. 处理GPU内存

SAM 3.1 将模型加载到 GPU 内存中并使用它。如果同时使用ComfyUI等其他GPU，使用完后释放一些内存会更稳定。

AI Select Candidates 面板上的“空闲 SAM 内存”从 GPU 内存中卸载模型。下次使用时会自动重新加载。
首选项 › SAM 3.1 的“卸载模型”与上面相同。
首选项 › “停止”SAM 3.1停止工作线程本身（在下次运行时自动启动）。

7.当事情进展不顺利时

如果失败，则会显示在日志字段中。 [コード] 内容 并将显示要做什么。详细日志是 ルートフォルダー\runtime\logs\setup.log（设置）和 worker.log（在运行时）。

代码意义应付
ROOT_NOT_CONFIGURED根文件夹未设置在首选项 › SAM 3.1 中选择根文件夹。
ROOT_INVALID没有文件夹/无法写入选择现有的可写文件夹。
SETUP_REQUIRED还没有执行环境运行“设置”。
CHECKPOINT_MISSING找不到型号/不是 SAM 3.1 的型号步骤3 根据 sam3.1_multiplex.pt 以及根文件夹中的配置文件。.pt 如果有多个项目，请移动不需要的项目。
PYTHON_UNSUPPORTED未找到 Python 3.12 或更高版本步骤1 并放入 Python （必须从 py 启动器中找到）。
NETWORK_CONSENT_REQUIRED没有下载权限步骤4 开启“允许外部AI服务”适用然后再次设置（消息显示“隐私”，但设置位于界面的页面上）。
VENV_CREATE_FAILED无法创建专用环境检查可用磁盘空间和文件夹权限，然后重试。
PIP_FAILED无法准备点重新设置一下。
TORCH_INSTALL_FAILEDPyTorch安装失败检查您的网络和 setup.log，然后重试。
SAM31_INSTALL_FAILEDSAM 3 主机安装或操作测试失败检查安装日志。线下实施第8章。
CUDA_UNAVAILABLE无法使用GPU（CUDA）检查您的 NVIDIA GPU 和驱动程序。仅 CPU 不足以提供实际速度。
CUDA_MISMATCHPyTorch和驱动CUDA不匹配更新您的 NVIDIA 驱动程序，然后再次尝试设置。
WORKER_START_FAILED工人没有启动检查worker.log。
HEALTH_FAILED启动但没有响应尝试“重新启动”，如果不起作用，请检查worker.log。
MODEL_LOAD_FAILED加载模型失败检查worker.log。如果模型文件已损坏，请重新安装。
OOMGPU 内存不足关闭其他 GPU 密集型应用程序，例如 ComfyUI，或释放其内存并重试。
COMPATIBILITY_UNSUPPORTED不支持安装的 SAM 3 版本。请等待LoomStroke的更新或向开发者报告。
CANCELLED设置已取消再次按“设置”即可从上次中断的位置继续。

如果在使用带有 AI Select 的工具时收到类似“SAM 3.1 未设置”的消息，它也对应于上表中的代码。环境设置 › 检查SAM 3.1 的状态栏。

8. 离线安装/删除

离线安装 SAM 3 装置

GitHub facebookresearch/sam3 一组 (pyproject.toml 文件夹包含） ルートフォルダー\runtime\sam3-src ，SAM 3 主体将从那里安装。但是，PyTorch 等部件需要从网络下载。

删除

  1. 按首选项 › SAM 3.1 中的“停止”以停止工作器。
  2. 删除整个根文件夹（专用环境和模型仅在该文件夹中，不会影响LoomStroke本身或其他Python）。
  3. 首选项 › 清除 SAM 3.1 的根文件夹字段，然后按 OK。

请在 Hugging Face facebook/sam3.1 页面上查看 SAM 3.1 型号的使用条款。
