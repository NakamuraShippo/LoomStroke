실행 및 시작 화면

윈도우에서는 설치 폴더의 boot_LoomStroke.bat 더블 클릭하면 실행됩니다. 실행 직후 중앙에 '새 문서...'와 '열기...'가 함께 나타나며, 최근 사용한 파일도 여기에 목록으로 표시됩니다.

처음 실행할 때는 윈도우의 표시 언어 우선순으로 지원 언어를 찾아 화면 언어를 결정합니다(지원 언어가 없으면 영어). 패널 배치는 '레이아웃을 리셋'과 같은 표준 배치가 됩니다. 언어는 이후에 환경 설정 › 인터페이스 의 '언어'로 변경됩니다.

펜타블릿의 펜 압력을 사용할 경우 반드시 boot_LoomStroke.bat내부에서 python.exe 을 사용하여 시작하세요.pythonw.exe 이곳에서 시작하면 테블릿은 인식되지만 펜 압력이 항상 0이 될 수 있습니다.

×(닫기)/ Esc어떤 것도 삭제하지 않습니다. 후속 시도에서도 추천 항목이 표시됩니다. 복구에 실패해도 추천 항목은 남습니다.

자동 저장의 켜짐/꺼짐 및 간격은 환경 설정 › 파일 I/O 을 통해 설정합니다. 자동 저장을 끄면, 캐시 후에 저장되지 않은 변경 내용을 복구할 수 없습니다.

2. 첫 번째 이미지

이 사용 설명서의 스크린샷은 한 장의 일러스트를 열고 그 위에 그리는 과정을 따라 촬영했습니다. 동일한 절차를 통해 기본 기능을 모두 체험할 수 있습니다.

  1. 파일 > 열기（Ctrl+OPNG 등의 이미지를 (에서) 열면 이미지의 크기만큼 캔버스가 생성되고 이미지는 하나의 레이어가 됩니다.
  2. 레이어 패널 아래의 ＋(추가)로 새 레이어를 생성하고, 이름을 더블 클릭하여 '그림 그리기' 등으로 변경합니다. 원래 그림과 다른 레이어에 그려서, 나중에 삭제하거나 이동해도 원래 그림이 손상되지 않습니다.
  3. 베이직 펜（B)에서 파형이나 별을 그릴 수 있습니다.
  4. 추가로 새 레이어를 생성하고, 펜으로 원을 그려서,채우기내부를 클릭하여 색상을 흐르게 합니다.
  5. 텍스트（T)이나수직 텍스트캔버스를 클릭하고 텍스트를 입력합니다.
  6. 일러스트 레이어를 선택하여필터 레이어추가하면 원래 그림을 바꾸지 않고 블러나 색 조정을 적용할 수 있습니다.

  3. 프레임을 분할을 누릅니다. '프레임 수정 중...'이 사라지면 반영됩니다.
  4. 이미지가 한 코마에만 보이거나 숨어 있는 경우,경계와 내용 수정의 '수정할 내용'에서 '전체가 코마 외' 등을 선택하고,프레임을 채우기와캔버스에서 조정을 바로 고치겠습니다.
  5. 전체가 마음에 들지 않으면되돌리기분할 전으로 되돌려서 처리를 바꾸고 다시 분할합니다.

  3. 추가 그리기 시:이 부분을 픽셀화을 누르고 나서이 부분을 처리을 누르고, 펜이나 지우개로 그립니다.

  5. 취소하고 싶을 때이 부분을 벡터로 되돌리기을 누릅니다.
