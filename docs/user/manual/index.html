LoomStroke 説明書

ラスター描画・ベクター・テキスト・複数ページ・漫画制作・AI 連携を 1 つの画面で扱うペイントアプリ LoomStroke の使いかたを、実際の画面とともに説明します。すべてのツール、すべてのパネルとその設定項目を網羅しています。

1. はじめに

起動とスタート画面

Windows では、インストールフォルダの boot_LoomStroke.bat をダブルクリックすると起動します。起動直後は、中央に「新規ドキュメント…」と「開く…」が並んだスタート画面が出ます。最近使ったファイルもここに一覧表示されます。

ペンタブレットの筆圧を使う場合は、必ず boot_LoomStroke.bat（内部で python.exe を使用）から起動してください。pythonw.exe から起動すると、タブレットは認識されても筆圧が常に 0 になることがあります。

自動保存からの復元

アプリが強制終了・クラッシュした場合、次回起動時にこのダイアログが出ます。一覧には自動保存された日時・ファイル名（保存前なら「未保存」）・セッション ID が並びます。

ボタン動作
復元選択した自動保存ファイルを開いて作業を再開します。
破棄して新規開始自動保存ファイルを削除し、通常どおり起動します。

自動保存の有効/無効と間隔は 環境設定 › ファイルI/O で設定します。自動保存をオフにすると、クラッシュ後に未保存の変更を復元できません。

2. はじめての1枚

この説明書のスクリーンショットは、1 枚のイラストを開いて描き加えていく流れで撮影しています。同じ手順で基本操作をひととおり体験できます。

  1. ファイル › 開く（Ctrl+O）で PNG などの画像を開きます。画像のサイズのキャンバスができ、画像は 1 枚のレイヤーになります。
  2. レイヤーパネル下の ＋（追加）で新規レイヤーを作り、名前をダブルクリックで「描き込み」などに変更します。元の絵とは別のレイヤーに描くと、後から消したり動かしたりしても元の絵が傷みません。
  3. ベーシックペン（B）で波線や星を描き加えます。
  4. さらに新規レイヤーを作り、ペンで円を描いて、塗りつぶしで内側をクリックして色を流し込みます。
  5. テキスト（T）や縦書きテキストでキャンバスをクリックし、文字を入力します。
  6. イラストのレイヤーを選んでフィルターレイヤーを追加すると、元の絵を書き換えずにぼかしや色調整をかけられます。
  7. ファイル › 保存（Ctrl+S）で .lstroke 形式に保存し、ファイル › 書き出し（Ctrl+E）で PNG などの画像にします。
通常の描画はレイヤーパネルで選択中のレイヤー（左端に紫のバーが付いた行）に対して行われます。コマ枠レイヤーでは「ここで描く」でそのコマの描画先へ戻れます。空コマのラフは、最初に有効な線を描いたときにレイヤーが作られます。

3. ツール

ツールバーとグループ

左端のツールバーはツールグループ単位でボタンが並びます。右下に小さな三角が付いたボタンは複数のツールを持ち、長押し（約 0.35 秒）でフライアウトメニューが開いて切り替えられます。ボタンの絵柄は最後に使ったツールになります。

このほか単独ボタンとして 移動、消しゴム、スポイト があります。

ツールを選ぶと、ツールプロパティバー（メニュー直下）とコンテキストツールバー（キャンバス上）にそのツールの設定が表示されます。バー左端の「プリセット」で設定の組み合わせを呼び出し、「保存」「削除」で管理できます。「ツール設定」（ペンは「ペン設定」）ボタンを押すと、折りたたみ式の詳細設定が開きます。この説明書では、詳細設定はすべてのセクションを展開した状態で掲載しています。

ベーシックペン B

筆圧・傾きに対応したラスターブラシです。プリセット「スケッチ」などが用意されており、ブラシマネージャーから Photoshop の ABR ブラシや PNG 画像のブラシ先端も取り込めます。

  4. Enter または線から離れた場所をクリックで確定、Esc で取り消します。

コマの領域内容を見せる範囲です。分割や境界の変更で形が変わります。
枠線見た目の線です。上辺・右辺・下辺・左辺ごとに分かれていて、一辺だけ消したり描き直したりできます。枠線を消しても、コマの領域はそのまま残ります。
コマの内容そのコマに所属する画像・ラフ・フキダシです。レイヤーパネルではコマの中の「内容」にまとまっています。分割すると、内容も新しいコマへ振り分けられます。
クリップコマの領域の外側を隠す表示です。隠れた部分の画素は消えていないので、位置を戻せば再び見えます。
コマ枠レイヤーへの変換テンプレート適用で作ったコマは、最初からコマ枠レイヤーです。古い文書などで、選んだコマにコマ枠レイヤーに変換が表示されたら押してください。このボタンが出ているコマでは、追加操作のほとんどが押せません。画像のドロップや結合では、必要なコマが自動で変換されます。

「選択」は3種類あります。ボタンによって、どれを先に選ぶかが違います。

普通の画像レイヤーとの違い：レイヤーパネルにただ置いた画像は、どのコマにも所属しません。クリップされず、分割しても振り分けられません。コマに入れたい画像は、画像ファイルをコマへドロップしてください。ドロップした画像はコマの「内容」に入り、クリップされ、「コマを埋める」「画像全体を収める」などの構図調整が使えます。構図調整は、ドロップで置いた画像だけが対象です。

確定ボタンはありません。分割・境界変更・手直しなどの操作は、ボタンを押すと（ドラッグは離したときに）そのまま反映されます。大きなページでは準備に時間がかかり、その間は「コマの変更を処理中…」と表示されて、すべてのボタンが押せません。結果が気に入らなければ元に戻す（Ctrl+Z）で戻します。ドラッグ中なら Esc でそのドラッグを取り消せます。

割り直し・配置

内容を入れたあとでもコマを割り直せます。分割では、各内容をいちばん重なりが大きい新しいコマへ振り分けます。重なりが同じもの、全体がコマの外にあるもの、範囲を判定できないものは、元のコマ側に残ります。振り分けを手で変える一覧はありません。結果が違うときは元に戻すか、レイヤーパネルで内容を移してください。

練習：4つの手順

練習は新しいファイルか、複製したファイルで行ってください。各手順は実装に沿って書いたもので、画面での確認が済んでいない部分があります。途中で違う表示が出たら、上のボタンが押せない・エラーが出るときを確認してください。
練習1：最初の1ページを作る
  1. 新しいファイルを作り、ウィンドウ メニューから「Comic」を表示して「コマ割り」タブを開きます。
  2. テンプレートで「3コマ」などを選び、テンプレート適用を押します。レイヤーパネルに「コマ 1」…が作られます。
  3. ツールを Comic にして、1つ目のコマをクリックします。パネルに「選択中: コマ 1」と出ることを確認します。
  4. ここで描くを押し、ペンでラフを描きます。はみ出した部分はコマの外で隠れます。
  5. 描き直したいときは元に戻す。別のラフを重ねたいときは新しくラフを描くを押します。
練習2：複数の画像をドロップする
  1. 練習1のページで、画像・フキダシを開きます。
  2. 「画像の収め方」をコマを埋める、「複数画像の配置先」を読み順で各コマに配布にします。
  3. エクスプローラーで画像を3枚選び、まとめてコマ 1の上へドロップします。コマ1から読み順に1枚ずつ入ります。
  4. 画像の位置を直したいときは、Comic ツールで画像をダブルクリックするか、境界と内容を手直しで内容を選んでキャンバスで調整をオンにし、ドラッグします。
  5. コマが足りないエラーが出たら、画像の枚数を減らすか、ドロップ先を前のコマにします。何も置かれていないので、そのままやり直せます。
練習3：絵を入れてから分割する
  1. 画像の入ったコマを選びます。
  2. 割り直し・配置を開き、「分割時の画像の扱い」を選びます。迷ったら移動にします。
  3. コマを分割を押します。「コマの変更を処理中…」が消えると反映されます。
  4. 画像が片方のコマにしか見えない、または隠れたときは、境界と内容を手直しの「手直しする内容」で「全体がコマ外」などを選び、コマを埋めるやキャンバスで調整で直します。
  5. 全体が気に入らなければ元に戻すで分割前に戻し、扱いを変えて分割し直します。
練習4：枠線の一部を加工する
  1. コマを選び、枠線を加工を開いて「加工する辺」で辺を選びます。
  2. ベクターのまま一部を抜くとき：ベクターの枠線を部分消去するを押し、Comic ツールで消したい部分をドラッグします。もっと消すときはボタンをもう一度押します。
  3. 描き足すとき：この辺をピクセル化を押してからこの辺を加工を押し、ペンや消しゴムで描きます。
  4. あとでコマの大きさを変えて線の長さが合わなくなったら、境界と内容を手直しの「手直しする辺」を選び、辺に沿って伸縮かこの辺に描くで直します。
  5. やめたいときはこの辺をベクターに戻すを押します。

10. 困ったときは

症状確認すること
描いても線が出ない／別のレイヤーに描かれるレイヤーパネルで対象レイヤーが選ばれているか、非表示・ロック・透明部分の保護になっていないかを確認します。選択範囲が残っていると範囲外には描けないので Ctrl+D で解除します。チャンネルタブで特定の成分だけを選んでいないかも確認してください。
筆圧が効かないboot_LoomStroke.bat から起動しているか、ペン設定の「筆圧感知」がオンか確認します。
パネルが見当たらない／配置が崩れたウィンドウ メニューで表示をオンにするか、ウィンドウ › レイアウトをリセット。Tab でスクリーンモードになっていないかも確認。
AI 機能が使えない環境設定 › インターフェース の「外部AIサービスを許可」、AI Effect ページの API キーと ComfyUI の接続先を確認します。AI Select は SAM 3.1 のセットアップが必要です。
グラデーションやパスが確定しないドラッグ後は編集状態です。Enter で確定します。
起動時に「Recovery」が出る前回が強制終了した印です。必要なら「復元」、不要なら「破棄して新規開始」。
フォントが置き換わって表示されるファイル › フォント診断 で欠落フォントを確認し、置換またはアウトライン化します。
コマ枠の操作が見当たらないウィンドウ メニューから「Comic」を表示し、「コマ割り」タブを選びます。操作欄と読み順一覧はタブ内のスクロールで確認できます。コマ枠レイヤーの手順を参照してください。
コマを変更したら画像やラフが消えた新しい領域の外に隠れている場合があります。境界と内容を手直しの「手直しする内容」で「全体がコマ外」などの対象を選び、「コマを埋める」や「キャンバスで調整」で位置・構図を直します。分割で別のコマへ振り分けられていないか、コマ・内容が非表示でないかも確認してください。戻したいときは「元に戻す」です。
サイズ変更後の枠線が短い／余る「元の画素を保持」の場合は、線の長さを自動で描き直しません。境界と内容を手直しの「手直しする辺」で辺を選び、「辺に沿って伸縮」か「この辺に描く」を使います。
共通表示の画像を直したら別コマも変わった一つの元データを共有しているためです。対象コマだけ変えたい場合は「このコマの共通表示を独立させる」を使います。
コマ割りのボタンがグレーで押せない／「コマ操作を実行できません」と出るコマを選んでいるか、選んだコマに「コマ枠レイヤーに変換」が出ていないか、「コマの変更を処理中…」でないかを確認します。詳しくはボタンが押せない・エラーが出るときを参照してください。
