LoomStroke 使用說明書

我們將解釋如何使用繪畫應用程式 LoomStroke，該應用程式可以在一個螢幕上處理光柵繪圖、向量、文字、多頁、漫畫製作和 AI 協作以及實際螢幕。它涵蓋了所有工具、所有面板及其設定。

安裝與更新（Windows）

文件如何使用
install.bat第一次設定。如果找不到 64 位元 Python 3.11 或更高版本，請在沒有管理員權限的資料夾中（.runtime) 準備Python。 NanoBanana 依賴項 (google-genai) 也作為標準安裝。完成後 boot_LoomStroke.bat 從 開始。
update.bat更新至最新版本。若以 ZIP 檔案安裝，則請在無 Git 的情況下取得公開版，並user_data 會保留原有的執行環境，僅更換主程式（舊主程式將 .update-backups 將暫存於此處，若失敗則會恢復）。若以 Git 安裝，僅在本地無變更時才可更新至最新版本。更新後 install.bat 將自動執行。
boot_LoomStroke.bat正常啟動。
boot_LoomStroke_noAI.bat啟動時不會載入 AI 功能（--no-ai）。AI Effects Manager、AI Select、提示編輯器、NanoBanana、GPT Image 2、ComfyUI、圖庫等面板，以及環境設定中的「AI 效果」、「SAM 3.1」、「LoomStroke MCP」頁面將不會顯示。此啟動不會儲存面板配置，因此通常啟動的配置不會改變。

詳細步驟請參閱附贈的 docs/user/INSTALL_AND_RUN.md 請參閱應用程式標題欄（LoomStroke v…）與 幫助 › 關於 LoomStroke 可於此確認。

啟動和啟動螢幕

Windows 上，請參閱安裝資料夾的 boot_LoomStroke.bat 雙擊即可啟動。啟動後，螢幕中央會出現「新建文件…」與「開啟…」並列的啟動畫面，並會列出最近使用的檔案。

首次啟動時，將根據 Windows 顯示語言的優先順序尋找對應語言來決定畫面語言（若無對應語言則使用英文）。面板配置將與「重新設定佈局」相同之標準配置。語言後續可 環境設定 › 介面 可於「語言」中更換。

若要使用筆電筆的壓力功能，請務必 boot_LoomStroke.bat（內部中 python.exe 請從此處啟動。pythonw.exe 若從此處啟動，筆電筆雖會被識別，但壓力值可能始終為 0。

2.我的第一張照片

本手册中的屏幕截图是通过打开单个插图并添加到其中来获取的。您可以按照相同的步骤体验基本操作。

  1. 檔案 › 打開（Ctrl+O）打開 PNG 等影像。您将拥有一个与图像大小相同的画布，并且您的图像将是单层。
  2. 在圖層面板下 ＋使用（添加）创建一个新图层，然后双击将名称更改为“绘图”之类的名称。如果您在与原始图片不同的图层上绘制，即使稍后删除或移动它也不会损坏原始图片。
  3. 基本筆（B) 添加波浪線和星星。
  4. 新建一個圖層，用鋼筆畫一個圓，填充點擊內部以倒入顏色。
  5. 文字（T）和垂直排文字點擊畫布並輸入文字。
  6. 選擇插圖圖層過濾層通过添加 ，您可以模糊或调整颜色，而无需重写原始图片。
  7. 檔案 › 保存（Ctrl+S）在 .lstroke 儲存為格式，檔案 › 匯出（Ctrl+E）來創建 PNG 等圖像。
正常繪製是在圖層面板中選擇圖層（左側有紫色條的行）。框架邊框層现在，使用“在此处绘制”返回到该帧的绘制目的地。当您第一次绘制有效线条时，将为空白草图创建一个图层。

3. 工具

工具列和群組

左邊的工具列是工具組按鈕按單元排列。右下角的小三角形按鈕有多種工具，長按（約0.35秒）彈出式選單將打開，您可以在它們之間進行切換。按鈕圖片是最後使用的工具。

在工具列的末尾，有用於繪圖顏色（左前）和背景顏色（右後）的方塊。

話意義
框架面積這是顯示內容的範圍。形狀透過劃分或改變邊界而改變。
框線這是一條視覺線。它分為上、右、下、左四面，您只能擦除或重畫一側。即使刪除邊框，邊框區域也將保持原樣。
框架的內容這些是屬於該框架的圖像、粗糙的演講和氣球。在圖層面板中，框架內的「內容」被組織起來。劃分時，內容也會被分配到新的幀中。
剪輯這是隱藏框架區域外部的顯示。隱藏的像素並沒有消失，所以如果你將它們移回去，它們將再次變得可見。
轉換為框架邊框層透過應用範本建立的框架從一開始就是框架邊框層。選擇舊文檔等中的框架。轉換為框架邊框層當它出現時按下。大多數附加操作無法在顯示此按鈕的框架上按下。刪除或合併影像時，會自動轉換必要的影格。

症狀要檢查的事情
當我在單獨的圖層上繪製/繪製時，線條不出現檢查是否在圖層面板中選擇了目標圖層，且該圖層未被隱藏、鎖定或透明部分受到保護。如果所選範圍仍然存在，則無法在該範圍之外進行繪製。 Ctrl+D 用 取消。確保您沒有在通道標籤中僅選擇特定成分。
筆壓不起作用boot_LoomStroke.bat 檢查它是否從 運行，以及筆設定中的“筆壓力靈敏度”是否打開。
面板遺失/放錯位置窗戶 開啟選單類別（圖層頁面/繪圖/漫畫/AI/其他）中的顯示，或視窗 › 重置佈局。Tab 確保它不是處於螢幕模式。
AI功能無法使用在“偏好設定”>“介面”中勾選“允許外部AI服務”，並在AI效果頁面中勾選API金鑰和ComfyUI的連線目的地。 AI Select 需要設定 SAM 3.1。boot_LoomStroke_noAI.bat 如果以 啟動，則不會顯示 AI 相關面板和設定頁面。boot_LoomStroke.bat 重新啟動。
漸層和路徑不固定拖曳後，處於編輯狀態。Enter 用 確認。
啟動時出現“LoomStroke — 恢復”這是上次被迫結束的徵兆。如果有必要，“恢復”，如果沒有，“丟棄並重新開始”。如果用×關閉，則不會刪除任何內容，下次會再次顯示。
螢幕上的語言與我想像的不同首次符合Windows的顯示語言。環境設定 › 介面 請在「語言」中註明。
更新/安裝失敗install.bat 再次運行它。郵編版本 update.bat 如果發生故障，將恢復到舊的主機。當手邊有變更時，Git 版本會停止更新。
當我嘗試撤消時，我收到“無法完成”在繼續之前，請按照狀態列中的說明檢查文件的狀態，如有必要，請將其儲存為其他名稱。
字體將被替換並顯示。檢查文件 › 字體診斷中是否有缺少的字體，並替換或概述它們。
我找不到框架邊框操作。視窗 › 漫畫 › 漫畫 ，然後選擇“框架分割”標籤。您可以透過在標籤內捲動來查看操作欄和閱讀順序清單。框架邊框圖層步驟請參考
換幀後影像和粗糙影像消失它可能隱藏在新區域之外。調整邊界和內容在“要修改的內容”下，選擇一個對象，例如“整個圖像在框外”，然後使用“填充框”或“在畫布上調整”來校正位置和構圖。請確保框架未分為單獨的框架，且框架/內容未隱藏。如果您想返回，請按一下「撤銷」。
調整大小後邊框過短/過大如果選擇“保留原始像素”，則線長不會自動重畫。調整邊界和內容在「要修改的邊緣」中選擇邊緣，然後使用「沿邊緣拉伸」或「在此邊緣上繪製」。
當我修正公共顯示影像時，其他畫面也發生了變化。這是因為它們共享一個來源資料。如果只想更改目標框架，請使用「使該框架的公共顯示獨立」。
幀分割按鈕呈灰色且無法按下/出現「無法執行幀操作」訊息。確保選擇了一個框架，並且所選框架不顯示“轉換為框架邊框圖層”，並且不顯示“正在處理對框架的變更...”。了解更多詳情當無法按下按鈕或發生錯誤時請參考
