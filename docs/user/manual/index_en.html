Launching and the start screen

For Windows, the installation folder boot_LoomStroke.bat Double-click to start it. Immediately after startup, a start screen appears with "New document..." and "Open..." lined up in the center. Recently used files are also listed here.

When started for the first time, the screen language is determined by searching for a compatible language in the priority order of Windows's display languages (if no compatible language is found, English is selected). The panel arrangement will be the same standard arrangement as "Reset Layout". language comes later Preferences › Interface You can change it with the "language".

When using pen pressure on a pen tablet, be sure to boot_LoomStroke.bat(Internally python.exe Please start from ).pythonw.exe When starting from , the pen pressure may always be 0 even though the tablet is recognized.

2. Your first artwork

The screenshots in this manual are taken by opening a single illustration and adding to it. You can experience the basic operations by following the same steps.

  1. File › Open（Ctrl+O) to open an image such as PNG. You'll have a canvas the size of your image, and your image will be a single layer.
  2. under the layers panel ＋Create a new layer with (Add), and double-click to change the name to something like "Drawing". If you draw on a separate layer from the original picture, the original picture will not be damaged even if you erase or move it later.
  3. basic pen（B) to add wavy lines and stars.
  4. Create a new layer and draw a circle with a pen,fill Click inside to pour the color.
  5. text（T) and vertical text Click on the canvas and enter text.
  6. Select the illustration layer filter layer By adding , you can blur or adjust colors without rewriting the original picture.
  7. File › Save（Ctrl+S) at .lstroke Save to format,File › Export（Ctrl+E) to create an image such as PNG.
Normal drawing is Layer selected in the layer panel(the row with the purple bar on the left).Frame border layer Now, use "Draw here" to return to the drawing destination for that frame. A layer will be created for the blank rough sketch when you first draw a valid line.
