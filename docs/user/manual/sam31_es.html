Guía de instalación de SAM 3.1

de LoomStroke AI Select Se explica aquí cómo preparar SAM 3.1 para usar la selección automática por inteligencia artificial. El proceso dura entre 30 minutos y 1 hora (puede tardar más según la velocidad de conexión).

1. ¿Qué es SAM 3.1?

SAM 3.1 es una inteligencia artificial de segmentación de imágenes publicada por Meta. En LoomStroke se utiliza para las siguientes funciones.

  • Herramienta de Selección de IA: Crea candidatos de selección a partir de palabras como 'cabello' o 'personaje' o mediante clics.
  • Panel AI Select Candidates：Combinar y crear capas de los candidatos encontrados.
  • Panel Manga Mask Assistant: Crea un máscara que combine páginas de manga, cuadros, notas y personajes.

SAM 3.1 es un modelo distinto al propio LoomStroke Entorno de ejecución especial Funciona como un pequeño servidor que se ejecuta en tu propia computadora. El botón 'Configuración' de LoomStroke crea automáticamente este entorno, pero El modelo principal (punto de control) debe descargarse y almacenarse por usted mismo es necesario. LoomStroke no descarga automáticamente el modelo.

SAM 3.1 no envía imágenes al exterior y procesa todo en su propio ordenador. El uso de internet solo ocurre durante la descarga de componentes (como PyTorch) al instalarlo y al obtener el modelo.

3. Procedimiento de instalación

Paso 1: Instalar Python 3.12 o superior

  1. python.org Descargue el instalador para Windows de Python 3.13 (o 3.12).
  2. Iniciar instalador y「py launcher」Instale manteniendo la configuración en la que se encuentra el lanzador de Python.
  3. Ejecuta en el prompt de comandos lo siguiente y Python 3.13.x se mostrará como indicado. Esto indica que está completo. 
    py -3.13 --version

La instalación py -3.13 → py -3.12 → py -3 → python Busca Python en orden, y utiliza el primero encontrado que sea de versión 3.12 o superior.

Paso 2: Crear un directorio para SAM 3.1

Colocar modelo y entorno de ejecución Carpeta raíz se creará. Colóquelo en un disco con mucha capacidad libre,Ruta con solo caracteres alfanuméricos en inglés se recomienda crearlo con.

Paso 6: Verificar el funcionamiento

  1. Abra una imagen en el lienzo y, desde la barra de herramientas, AI Select Elige (manteniendo pulsado el botón de grupo seleccionado).
  2. En la barra de propiedades, en 'Prompt', escriba lo que desea buscar (por ejemplo:hair、person、flower)
  3. Si los candidatos se muestran con color, se ha completado correctamente. Al hacer clic en 'Aplicar', se seleccionará el área correspondiente.

La primera ejecución carga el modelo (aproximadamente 3.5 GB) en la GPU, por lo que puede tardar un poco. Si el trabajador se detiene, se iniciará automáticamente durante la ejecución.

6. Manejo de memoria de GPU

SAM 3.1 carga el modelo en la memoria de la GPU. Si se ejecutan simultáneamente tareas que usan otra GPU (como ComfyUI), es recomendable liberar la memoria una vez terminadas para garantizar estabilidad.

Libera la memoria de SAM en el panel AI Select Candidates Descarga el modelo de la memoria de GPU. Se cargará automáticamente al usarlo de nuevo.
Configuración del entorno › SAM 3.1 › 'Desactivar modelo'Igual que arriba.
Configuración del entorno › 'Detener' en SAM 3.1 detiene el worker (se reiniciará automáticamente en la siguiente ejecución).

En caso de que aparezca un mensaje como 'SAM 3.1 no está configurado' al usar una herramienta en AI Select, también está relacionado con la tabla anterior. Por favor, verifique el estado de SAM 3.1 en la configuración del entorno.

8. Instalación y eliminación offline

Instalar SAM 3 en modo offline

de GitHub facebookresearch/sam3 de la serie (pyproject.toml en el directorio (que incluye) ルートフォルダー\runtime\sam3-src Al colocarlo aquí, SAM 3 se instalará desde ese punto. Sin embargo, componentes como PyTorch deben descargarse desde la red.

Eliminar

  1. Configuración del entorno › En SAM 3.1, pulse 'Detener' para detener el trabajador.
  2. Elimina completamente el directorio raíz (el entorno especial y los modelos también se encuentran aquí, y no afectan al propio LoomStroke ni a otros entornos de Python).
  3. Configuración del entorno › vacía el campo de la carpeta raíz de SAM 3.1 y haz clic en Aceptar.

Las condiciones de uso del modelo de SAM 3.1 se pueden verificar en la página de Hugging Face de facebook/sam3.1.
