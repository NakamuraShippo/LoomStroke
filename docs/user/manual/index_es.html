Iniciar y pantalla de inicio

En Windows, en el directorio de instalación de boot_LoomStroke.bat Se inicia al hacer doble clic. Inmediatamente después de iniciar, aparece una pantalla de inicio con 'Nuevo documento...' y 'Abrir...'. También se muestra una lista de archivos recientemente utilizados.

Al iniciar por primera vez, se buscará el idioma de correspondencia según el orden de prioridad del idioma de la interfaz de Windows para definir el idioma de la pantalla (si no hay idioma disponible, se usará inglés). La disposición de los paneles será la configuración estándar igual que con 'Restablecer disposición'. El idioma se puede cambiar más tarde. 10. Si tienes problemas

síntomas verificarlo
No se dibuja línea / se dibuja en otra capa Asegúrate de que la capa objetivo esté seleccionada en el panel de capas y que no esté oculta, bloqueada o protegida como transparente. Si hay un rango seleccionado, no podrás dibujar fuera de él. Ctrl+D Se desactiva en la pestaña de canales. Asegúrate de que no se haya seleccionado solo un componente específico.
No responde la presión del lápiz boot_LoomStroke.bat Verifique si se está ejecutando desde aquí o si la función 'detección de presión del lápiz' en la configuración del lápiz está activada.
No se encuentra el panel / se ha desordenado la disposición Ventana Activar o desactivar la visualización por categorías del menú (capas, página / dibujo / cómic / IA / otros)Ventana > Restablecer diseño。Tab Asegúrate de que no esté en modo pantalla.
Función de IA no disponible Verifique la opción 'Permitir servicios de inteligencia artificial externos' en la configuración del entorno › Interfaz, así como la clave de API y la conexión con ComfyUI en la página de efectos de IA. Para usar AI Select, es necesario realizar la configuración de SAM 3.1.boot_LoomStroke_noAI.bat Si se inicia así, no se mostrarán los paneles ni las páginas de configuración relacionadas con IA,boot_LoomStroke.bat se reiniciará con eso.
Los gradientes o los paths no se han determinado aún Está en estado de edición después de arrastrar.Enter se confirmará con ello.
Al iniciar, aparece 'LoomStroke — Restauración'Indica que la sesión anterior se cerró de forma forzada. Si es necesario, utilice 'Restaurar'; si no, use 'Eliminar y comenzar de nuevo'. Si se cierra con el símbolo ×, no se eliminará nada y se mostrará de nuevo en la próxima sesión.
El idioma de la pantalla no coincide con el esperado Inicialmente se ajustará al idioma de visualización de Windows.Configuración del entorno › Interfaz especifique el idioma.
Error al actualizar o instalar install.bat ejecutará de nuevo. Versión ZIP de update.bat Se vuelve al modelo anterior en caso de error. La versión Git detiene la actualización si hay cambios locales en tu equipo.
Al volver atrás aparece 'No se pudo completar'Verifique el estado del borrador según las indicaciones de la barra de estado y, si es necesario, guarde el documento con otro nombre antes de continuar.
Los fuentes se reemplazan y se muestran Verifica fuentes faltantes en 'Archivo > Diagnóstico de fuentes' y reemplaza o outline-iza las fuentes ausentes.
No se encuentra la operación de cuadro de imagen Ventana › Cómic › Comic Muestra en la pantalla y selecciona la pestaña 'División de cuadros'. Puedes ver la barra de operaciones y la lista de orden de lectura mediante desplazamiento dentro de la pestaña.Procedimiento de capas de cuadros Consulte este documento.
Al cambiar el cuadro, la imagen o el boceto se borró Puede estar oculto fuera del nuevo área.corregir límites y contenido En la opción 'contenido a corregir', selecciona objetos como 'todo fuera de cuadro' y corrige la posición o composición mediante 'rellenar cuadro' o 'ajustar en lienzo'. Asegúrate de que el cuadro no haya sido asignado a otro cuadro mediante división y que el cuadro y su contenido no estén ocultos. Para deshacer, utiliza 'volver a la versión anterior'.
la línea del marco es demasiado corta o sobra tras el cambio de tamaño Si se selecciona 'mantener los píxeles originales', no se redibujará automáticamente la longitud de las líneas.corregir límites y contenido Usa la opción 'Lado a reparar' para seleccionar un borde, y luego utiliza 'Estirar según el borde' o 'Dibujar en este borde'.
Cuando se modifica la imagen de visualización común, también cambia la otra cuadricula Porque comparte un mismo conjunto de datos. Si desea modificar solo una cuadra, use 'Hacer independiente la visualización común de esta cuadra'.
El botón de división de cuadros está en gris y no se puede pulsar / se muestra el mensaje 'No se puede realizar operaciones de cuadros'.Verifique si está seleccionando un cuadro, si no aparece la opción 'Convertir a capa de cuadro' en el cuadro seleccionado, o si no está en estado 'Procesando cambios de cuadro'.
