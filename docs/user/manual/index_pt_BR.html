manual do LoomStroke

Explica como usar a aplicação de pintura LoomStroke, que trata de desenho rasterizado, vetorial, texto, múltiplas páginas e criação de mangás em uma única tela, com explicações baseadas em telas reais. Aborda todos os ferramentas, todos os painéis e suas configurações específicas.

Início e tela inicial

No Windows, na pasta de instalação da boot_LoomStroke.bat Clique duas vezes para iniciar. Imediatamente após o início, uma tela de início com 'Novo documento...' e 'Abrir...' será exibida no centro. Os arquivos recentemente usados também serão listados aqui.

2. Primeira imagem

As capturas de tela deste manual foram feitas seguindo o fluxo de abrir uma única ilustração e acrescentar elementos. É possível experimentar todas as operações básicas seguindo o mesmo procedimento.

  1. Arquivo › Abrir（Ctrl+O Abra a imagem em formato PNG e outros no ( ). Um canvas com dimensões da imagem será criado e a imagem será um único camada.
  2. aba do painel de camadas ＋Use (Adicionar) para criar uma nova camada e, ao clicar com dois dedos no nome, altere para 'desenho', por exemplo. Desenhar em uma camada diferente da original permite remover ou mover posteriormente sem danificar a imagem original.
  3. Pincel básico（B para adicionar linhas onduladas ou estrelas).
  4. Crie uma nova camada, desenhe um círculo com o lápis e,Balde de tinta clique dentro para preencher a cor.
  5. Texto（T) ou Texto vertical Clique no canvas e digite o texto.
  6. Selecione a camada da ilustração e Camada de filtro Ao adicionar, é possível aplicar efeitos de desfoque ou ajustes de cor sem substituir a imagem original.
  7. Arquivo › Salvar（Ctrl+S) em .lstroke salvar no formato e Arquivo › Exportar（Ctrl+E) e converterão as imagens para formatos como PNG.

A barra de ferramentas da esquerda é grupo de ferramentas Os botões aparecem com base na unidade. Cores de fundo e de frente

No final da barra de ferramentas, há quatro quadrados: um para a cor de desenho (à esquerda, frente) e outro para a cor de fundo (à direita, trás).

clique no quadrado atrás Muda a cor de fundo. A cor de fundo será mantida até a próxima inicialização.
