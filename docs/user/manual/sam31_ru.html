Руководство по установке SAM 3.1

LoomStroke AI Select Мы объясним, как подготовить SAM 3.1 к использованию (автоматический выбор с помощью ИИ). Процесс займет примерно 30 минут до 1 часа (длительность может быть больше в зависимости от скорости вашего интернет-соединения).

1. Что такое SAM 3.1?

SAM 3.1 — это искусственный интеллект для сегментации изображений, опубликованный компанией Meta. В LoomStroke используются следующие функции на основе этого:

  • Инструменты AI Select: Создать кандидаты на выбор диапазона из слов и кликов, таких как "волосы" и "человек".
  • Панель выбора кандидатов AI: объединить и сложить найденные варианты.
  • Панель помощника по маскам для манги: Создание масок, таких как рамки, шары и люди с страниц манги.

SAM 3.1 является отдельным компонентом от основного тела LoomStroke.отдельная среда выполнения(запускается как небольшой сервер, работающий внутри вашего ПК). Кнопка «Настройка» в LoomStroke автоматически создает этот среду,Скачать только сам модель (checkpoint) и разместить самостоятельно.Нужно что-то сделать. LoomStroke не автоматически загружает модели.

SAM 3.1 не отправляет изображения за пределы локальной машины и обрабатывает их полностью на вашем собственном ПК. Интернет используется только для загрузки компонентов при установке (PyTorch и т.д.) и для получения модели.

2. Что вам нужно

вход Содержимое
OS Windows 10 / 11（64 bit）
GPU Рекомендуется использовать видеокарту NVIDIA (совместимую с CUDA). В ходе разработки и тестирования (на RTX 4090) для обработки одного изображения использовалось до 4,6 ГБ видеопамяти. Рекомендуется иметь не менее 8 ГБ видеопамяти.
Даже в отсутствие видеокарты установка пройдёт, но в итоговом тесте операции появится сообщение «CUDA не может быть использован» и остановится (использование только процессора не позволит достичь практической скорости).
Драйвер NVIDIA Новый драйвер. Для настройки версии CUDA 13.0 PyTorch используйте командную строку. nvidia-smi Выполнить и "Версия CUDA" в верхнем правом углу равна 13.0 или выше Убедитесь, что это так. Если отсутствует, обновите драйвер с официального сайта NVIDIA.
Python Python 3.12 или выше(Рекомендация 3.13). Должен быть установлен на вашем ПК отдельно от LoomStroke (Шаг 1）。
место на диске рекомендации 15 ГБ или больше(Модель примерно 3,5 ГБ + несколько ГБ, такие как PyTorch + для работы).
интернет Требуется только при установке (PyTorch имеет несколько гигабайт загрузок).
Аккаунт Hugging Face Требуется для получения модели (бесплатно).

3. Шаги установки

Шаг 1: Вставить Python 3.12 или выше

  1. python.org Скачайте установщик для Windows для Python 3.13 (или 3.12) с.
  2. Запустить установщик и「py launcher」Установка с настройками, включающими (Python Launcher).
  3. Запустите следующее в командной строке,Python 3.13.x Если отображается так, как указано, работа завершена. 
    py -3.13 --version

Установка состоит из py -3.13 → py -3.12 → py -3 → python Ищите Python и используйте первый найденный версии 3.12 или выше.

Шаг 2: Создать папку для SAM 3.1

Разместить модель и среду выполнения корневая папка Я сделаю на диске с большим количеством свободного места,путь, содержащий только полудлинные буквенно-цифровые символы Рекомендуется создавать с помощью

例：D:\SAM31

В этой папке вы разместили модель на шаге 3 и настроили среду выполнения (runtime папка) будет создана автоматически.

Шаг 3: Получить модель (checkpoint)

Модель SAM 3.1 — это модель от Hugging Face. facebook/sam3.1 Опубликовано на этой странице Требуется согласие на доступ (ограниченный)Это так.

  1. Hugging Face Создать аккаунт и войти.
  2. facebook/sam3.1 Открыть , прочитать условия использования, согласиться на обмен контактами и запросить доступ. Может быть короткая задержка на одобрение.
  3. После одобрения, из вкладки "Файлы и версии" Набор файлов репозитория（sam3.1_multiplex.pt(приблизительно 3,5 ГБ) и config.json файл конфигурации) и поместите его в папку на шаге 2.

Если вы знакомы с командой, вы можете получить её сразу с помощью официального инструмента Hugging Face (запустите после получения разрешения в браузере).

hf auth login Теперь вставьте токен, созданный на экране настроек Hugging Face (Доступные токены).hf Если команда не найдена, включите опцию «Добавить python.exe в переменную PATH» при установке Python и попробуйте снова, или скачайте её в браузере.

Модель находится непосредственно под корневой папкой или checkpoints・model Может быть размещён в подпапке. Имя файла — sam3.1_multiplex.pt Если да, используйте это, и если имя отличается, используйте .pt Используется только в случае одного файла (если файлов несколько, невозможно определить и будет считаться "не найдено"). LoomStroke не копирует и не перемещает модели.

Шаг 4 Разрешить LoomStroke подключаться к внешним сервисам

  2. 2 Включите «Разрешить внешние сервисы ИИ (ComfyUI, LLM Gateway, NanoBanana)».
  3. 3 Нажмите «Применить», чтобы сохранить.Установка учитывает сохранённые настройки, поэтому если вы просто включите программу, но не примениете её, она остановится на "Требуется разрешение на сеть".

Шаг 6 Проверка работы

  1. Откройте изображение на холсте и из панели инструментов AI Select (Удерживайте кнопку выбранной группы).
  2. Что вы хотите найти в поле "Prompt" на панели свойств (например,hair、person、flower) и нажмите "Запустить".
  3. Если кандидат отображается в цвете, это означает успех. Нажмите «Применить», чтобы выбрать диапазон.

Первый запуск займет некоторое время, так как модель (примерно 3,5 ГБ) будет загружаться на GPU. Если рабочий процесс остановлен, он будет автоматически запущен во время выполнения.

4. Экран настройки SAM 3.1

Настройки среды › Каждый элемент SAM 3.1 (числа являются Шаг 5 )

Модель:загружено (загружено в GPU)/не загружено (не загружено).

4 Настройка/Отмена Подготовить среду выполнения/прервать подготовку на полпути.
5 Запуск/остановка/перезапуск Ручное управление рабочими процессами.
6 Загрузить модель / Выгрузить модель Загрузить модель в/выгрузить из видеопамяти (работники остаются запущенными).
7 поле журнала Показывает прогресс настройки и запуска, а также детали ошибок и способы их устранения.

6. Работа с памятью GPU

SAM 3.1 загружает модель в память видеокарты и использует её. Если вы работаете одновременно с другими видеокартами, такими как ComfyUI, для более стабильной работы рекомендуется освобождать часть памяти после завершения использования.

Свободная память SAM на панели «Выбор кандидатов AI»Удалить модель из видеопамяти. Она будет автоматически перезагружена при следующем использовании.
Параметры › «Очистить модель» для SAM 3.1 То же самое, что выше.
Параметры › "Остановить" SAM 3.1 Останавливает сам рабочий процесс (запускается автоматически на следующем запуске).

7. Когда всё идёт не так

Если произойдёт сбой, он будет отображаться в поле журнала. [コード] 内容 и то, что нужно сделать, будет отображаться. Подробный журнал находится ルートフォルダー\runtime\logs\setup.log(настройка) и worker.log(во время выполнения).

код смысл сопротивление
ROOT_NOT_CONFIGURED Корневая папка не задана Выберите корневую папку в Настройках › SAM 3.1.
ROOT_INVALID Каталог отсутствует/невозможно записывать в него Выберите существующую папку для записи.
SETUP_REQUIRED Окружение для выполнения ещё не создано Запустите "Настройку".
CHECKPOINT_MISSING Модель не найдена/не является моделью для SAM 3.1 Шаг 3 по sam3.1_multiplex.pt и конфигурационный файл в корневой папке..pt Если есть несколько элементов, переместите ненужные.
PYTHON_UNSUPPORTED Не найдено Python 3.12 или выше Шаг 1 и поместите в Python (должен быть найден через py launcher).
NETWORK_CONSENT_REQUIRED Отсутствует разрешение на скачивание Шаг 4 Включите "Разрешить внешние сервисы ИИ" в Применить и затем настройте его снова (сообщение говорит «Конфиденциальность», но настройки находятся на странице в интерфейсе).
VENV_CREATE_FAILED Не удалось создать отдельную среду Проверьте свободное место на диске и разрешения папки и попробуйте снова.
PIP_FAILED Не удалось подготовить pip Настройте снова.
TORCH_INSTALL_FAILED Не удалось установить PyTorch Проверьте сеть и файл setup.log и попробуйте снова.
SAM31_INSTALL_FAILED Неудача при установке или работе с основной единицей SAM 3 Проверьте setup.log. Оффлайн-реализация Глава 8。
CUDA_UNAVAILABLE Невозможно использовать GPU (CUDA)Проверьте вашу видеокарту NVIDIA и драйверы. Только процессор не обеспечит практическую скорость.
CUDA_MISMATCH PyTorch и драйвер CUDA не совпадают Обновите драйверы NVIDIA, затем попробуйте установить программу снова.
WORKER_START_FAILED работник не запускается Проверьте файл worker.log.
HEALTH_FAILED запускается, но не отвечает Попробуйте "перезапустить", и если это не сработает, проверьте worker.log.
MODEL_LOAD_FAILED Не удалось загрузить модель Проверьте worker.log. Если файл модели повреждён, переустановите его.
OOM Недостаточно памяти видеокарты Закройте другие приложения, требующие значительных ресурсов видеокарты, такие как ComfyUI, или освободите их память и попробуйте снова.
COMPATIBILITY_UNSUPPORTED Версия SAM 3, установленная, не поддерживается.Пожалуйста, подождите обновления LoomStroke или сообщите разработчику.
CANCELLED Настройка была отменена Нажмите "Настройка" снова, чтобы продолжить с места, где вы остановились.

Если появляется сообщение вроде «SAM 3.1 не настроен» при использовании инструмента с AI Select, это также соответствует коду в таблице выше. Настройки среды › Проверьте столбец «Статус» для SAM 3.1.

8. Оффлайн-установка/удаление

Установка модуля SAM 3 без подключения к интернету

GitHub facebookresearch/sam3 Набор (pyproject.toml папка содержащая) ルートフォルダー\runtime\sam3-src , тело SAM 3 будет установлено с этого места. Однако компоненты, такие как PyTorch, требуют загрузки с сети.

удалить

  1. Нажмите "Остановить" в Настройках › SAM 3.1, чтобы остановить рабочий процесс.
  2. Удалить всю корневую папку (используемая среда и модели находятся только в этой папке и не повлияют на сам LoomStroke или другие Python-среды).
  3. Параметры › Очистить поле корневой папки для SAM 3.1 и нажать ОК.

Пожалуйста, проверьте условия использования модели SAM 3.1 на странице Hugging Face facebook/sam3.1.
