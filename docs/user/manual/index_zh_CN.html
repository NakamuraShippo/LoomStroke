LoomStroke 使用说明书

我们将解释如何使用绘画应用程序 LoomStroke，该应用程序可以在一个屏幕上处理光栅绘图、矢量、文本、多页、漫画制作和 AI 协作以及实际屏幕。它涵盖了所有工具、所有面板及其设置。

一、简介

启动和启动屏幕

对于 Windows，安装文件夹 boot_LoomStroke.bat 双击启动它。启动后，立即出现一个开始屏幕，中间排列着“新文档...”和“打开...”。最近使用的文件也列在这里。

首次启动时，按照Windows显示语言的优先顺序搜索兼容语言来确定屏幕语言（如果没有找到兼容语言，则选择英语）。面板排列将与“重置布局”相同的标准排列。语言是后来的 首选项 › 界面 您可以使用“语言”来更改它。

在数位板上使用笔压时，请务必 boot_LoomStroke.bat（内部 python.exe 请从）开始。pythonw.exe 从 开始时，即使识别了数位板，笔压也可能始终为 0。

2.我的第一张照片

本手册中的屏幕截图是通过打开单个插图并添加到其中来获取的。您可以按照相同的步骤体验基本操作。

  1. 文件 › 打开（Ctrl+O）打开 PNG 等图像。您将拥有一个与图像大小相同的画布，并且您的图像将是单层。
  2. 在图层面板下 ＋使用（添加）创建一个新图层，然后双击将名称更改为“绘图”之类的名称。如果您在与原始图片不同的图层上绘制，即使稍后删除或移动它也不会损坏原始图片。
  3. 基本笔（B) 添加波浪线和星星。
  4. 新建一个图层，用钢笔画一个圆，填充单击内部以倒入颜色。
  5. 文本（T）和竖排文字单击画布并输入文本。
  6. 选择插图图层过滤层通过添加 ，您可以模糊或调整颜色，而无需重写原始图片。
  7. 文件 › 保存（Ctrl+S）在 .lstroke 保存为格式，文件 › 导出（Ctrl+E）来创建 PNG 等图像。
正常绘制是在图层面板中选择图层（左侧有紫色条的行）。框架边框层现在，使用“在此处绘制”返回到该帧的绘制目的地。当您第一次绘制有效线条时，将为空白草图创建一个图层。

3. 工具

工具栏和组

左边的工具栏是工具组按钮按单元排列。右下角的小三角按钮有多种工具，长按（约0.35秒）弹出菜单将打开，您可以在它们之间进行切换。按钮图片是最后使用的工具。

此外，作为独立按钮 移动、橡皮擦、滴管、测量 有。

绘图颜色和背景颜色

在工具栏的末尾，有用于绘图颜色（左前）和背景颜色（右后）的方块。

点击前面的方块更改绘图颜色。
点击后面的方块更改背景颜色。下次启动后背景颜色保持不变。
右上箭头 / X交换前景色和背景色（编辑 › 交换前景色和背景色）。
左下小黑白/ D返回黑白（编辑 › 将前景色和背景色重置为默认设置）。

当你选择一个工具时，工具属性栏（菜单正下方）和上下文工具栏该工具的设置将显示（在画布上）。您可以使用栏左端的“预设”来调用设置组合，并使用“保存”和“删除”来管理它们。“工具设置”（对于笔，请按“笔设置”）按钮打开可折叠的高级设置。在本手册中，详细设置以展开的所有部分显示。

10.当你遇到困难时

症状要检查的事情
当我在单独的图层上绘制/绘制时，线条不出现检查是否在图层面板中选择了目标图层，并且该图层未被隐藏、锁定或有透明部分受到保护。如果所选范围仍然存在，则无法在该范围之外进行绘制。 Ctrl+D 用 取消。确保您没有在通道选项卡中仅选择特定成分。
笔压不起作用boot_LoomStroke.bat 检查它是否从 运行，以及笔设置中的“笔压力灵敏度”是否打开。
面板丢失/放错位置窗户 打开菜单类别（图层页面/绘图/漫画/AI/其他）中的显示，或窗口 › 重置布局。Tab 确保它不是处于屏幕模式。
AI功能无法使用在“偏好设置”>“接口”中勾选“允许外部AI服务”，并在AI效果页面中勾选API密钥和ComfyUI的连接目的地。 AI Select 需要设置 SAM 3.1。boot_LoomStroke_noAI.bat 如果以 启动，则不会显示 AI 相关面板和设置页面。boot_LoomStroke.bat 重新启动。
渐变和路径不固定拖动后，处于编辑状态。Enter 用 确认。
启动时出现“LoomStroke — 恢复”这是上次被迫结束的征兆。如果有必要，“恢复”，如果没有，“丢弃并重新开始”。如果用×关闭，则不会删除任何内容，下次会再次显示。
屏幕上的语言与我想象的不同首次匹配Windows的显示语言。首选项 › 界面 请在“语言”中注明。
更新/安装失败install.bat 再次运行它。邮编版本 update.bat 如果出现故障，将恢复到旧的主机。当手头有更改时，Git 版本会停止更新。
当我尝试撤消时，我收到“无法完成”在继续之前，请按照状态栏中的说明检查文档的状态，如有必要，请将其保存为其他名称。
字体将被替换并显示。检查文件 › 字体诊断中是否有缺失的字体，并替换或概述它们。
我找不到框架边框操作。窗口 › 漫画 › 漫画 ，然后选择“框架分割”选项卡。您可以通过在选项卡内滚动来查看操作栏和阅读顺序列表。框架边框图层步骤请参考
换帧后图像和粗糙图像消失它可能隐藏在新区域之外。调整边界和内容在“要修改的内容”下，选择一个对象，例如“整个图像在框外”，然后使用“填充框”或“在画布上调整”来校正位置和构图。请确保框架未分为单独的框架，并且框架/内容未隐藏。如果您想返回，请单击“撤消”。
调整大小后边框过短/过大如果选择“保留原始像素”，则线长不会自动重画。调整边界和内容在“要修改的边缘”中选择边缘，然后使用“沿边缘拉伸”或“在此边缘上绘制”。
当我修正公共显示图像时，其他帧也发生了变化。这是因为它们共享一个源数据。如果只想更改目标框架，请使用“使该框架的公共显示独立”。
帧分割按钮呈灰色且无法按下/出现“无法执行帧操作”消息。确保选择了一个框架，并且所选框架不显示“转换为框架边框图层”，并且不显示“正在处理对框架的更改...”。了解更多详情当无法按下按钮或发生错误时请参考
