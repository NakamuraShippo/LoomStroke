Guia de instalação do SAM 3.1

do LoomStroke AI Select Explicação do procedimento para preparar a SAM 3.1 para uso com seleção automática por IA. O processo leva entre 30 minutos e 1 hora (pode demorar mais dependendo da velocidade da conexão de internet).

1. O que é SAM 3.1

O SAM 3.1 é um modelo de inteligência artificial de segmentação de imagens publicado pela Meta. O LoomStroke utiliza as seguintes funcionalidades com esse modelo.

  • ferramenta AI Select: cria sugestões de seleção a partir de palavras como 'cabelo' ou 'pessoa' ou ao clicar.
  • Painel AI Select Candidates: combinar e camada dos candidatos encontrados.
  • Painel Manga Mask Assistant: Crie um mascarado combinando páginas de mangá, quadros, notas e personagens.

SAM 3.1 é um produto distinto do ambiente de execução especial funciona como um pequeno servidor que executa no seu próprio computador. O botão 'Configuração' do LoomStroke cria automaticamente esse ambiente, mas O modelo principal (checkpoint) deve ser baixado e armazenado por si só é necessário. O LoomStroke não baixa automaticamente o modelo.

O SAM 3.1 processa todas as imagens localmente, sem enviar para fora do computador. O uso da internet ocorre apenas durante o download de componentes (como PyTorch) e na obtenção do modelo.

2. O que é necessário

Entrada conteúdo
OS Windows 10 / 11（64 bit）
GPU Recomendamos fortemente a utilização de GPUs da NVIDIA (com suporte a CUDA)Durante a verificação de desenvolvimento (com RTX 4090), usamos até aproximadamente 4,6 GB de memória GPU por imagem. É recomendado ter pelo menos 8 GB de memória GPU.
Mesmo sem GPU, a instalação pode ser realizada, mas no teste final será exibido "CUDA não disponível" e o programa será interrompido (o uso apenas da CPU não será suficientemente rápido para uso prático).
driver NVIDIA Novo driver. A instalação requer a versão 13.0 do CUDA do PyTorch, portanto, no prompt de comando, nvidia-smi Executar para que a versão CUDA no canto superior direito seja 13.0 ou superior Verifique se está ativo. Caso contrário, atualize o driver da NVIDIA no site oficial.
Python Python 3.12 ou superior（Recomendado para 3.13). É necessário ter o LoomStroke instalado separadamente no PC (Passo 1）。
espaço livre no disco Referência 15 GB ou mais(Model aproximadamente 3,5 GB + vários GB como PyTorch + para trabalho).
internet Necessário apenas na instalação (há um download de vários GB com PyTorch).
Conta Hugging Face Necessário para obter o modelo (gratuito).

3. Procedimento de instalação

Passo 1: Instalar Python 3.12 ou superior

  1. python.org Baixe o instalador para Windows do Python 3.13 (ou 3.12).
  2. inicie o instalador e「py launcher」Instale mantendo as configurações do (launcher de Python).
  3. Execute o seguinte no prompt de comando e Python 3.13.x Aparecerá assim, indicando que está concluído. 
    py -3.13 --version

a instalação é py -3.13 → py -3.12 → py -3 → python Procure por Python e use o primeiro encontrado com versão 3.12 ou superior.

Passo 2: Criar um diretório para o SAM 3.1

Colocar o modelo e o ambiente de execução Pasta raiz Será criado. Em um disco com grande espaço livre,Caminho contendo apenas caracteres numéricos e alfabéticos é recomendável criar com

例：D:\SAM31

Neste diretório, coloque o modelo no passo 3 e execute o ambiente de configuração no passo 5 (runtime pasta) será criada automaticamente.

Passo 3: Obter o modelo (checkpoint)

  1. Hugging Face crie uma conta e faça login.
  2. facebook/sam3.1 para ler os termos de uso e concordar com o compartilhamento de contato, solicitando o acesso. Pode ser necessário esperar um pouco até que a solicitação seja aprovada.
  3. Após a aprovação, no tab 'Files and versions' todos os arquivos do repositório（sam3.1_multiplex.pt（aproximadamente 3,5 GB）e config.json Baixe os arquivos de configuração (como os de configuração) e coloque-os na pasta do passo 2.

O modelo está localizado na pasta raiz ou checkpoints・model pode ser armazenado em um subpasta. O nome do arquivo será sam3.1_multiplex.pt se for o caso, use esse, caso contrário .pt Será usado apenas quando houver um único arquivo (se houver mais de um, será considerado inexistente e tratado como 'não encontrado'). O LoomStroke não copia nem move modelos.

Etapa 4: Permita a conexão com serviços externos no LoomStroke

Permita a conexão de rede para baixar componentes como PyTorch durante a configuração.

  1. Editar › Configurações do ambiente（Ctrl+,abrir )1 escolha a 'Interface'.
  2. 2 Ative a opção "Permitir serviços de IA externos (ComfyUI, LLM Gateway, NanoBanana)".
  3. 3 Aperte 'Aplicar' para salvar.A instalação exibe as configurações salvas, então, apenas ativando não será aplicado e a operação poderá parar com a mensagem "Permissão de rede necessária".

Passo 6: Verificar o funcionamento

  1. Abra a imagem no canvas e, na barra de ferramentas, AI Select escolha (pressione e mantenha pressionado o botão de grupo selecionado).
  2. Propriedade 'Prompt' da barra de propriedades para o que deseja procurar (ex:hair、person、flower)
  3. Se os candidatos estiverem destacados com cor, o processo foi bem-sucedido. Ao clicar em 'Aplicar', o selecionado será a área escolhida.

A primeira execução carrega o modelo (aproximadamente 3,5 GB) na GPU, o que pode levar um pouco de tempo. Se os trabalhadores estiverem parados, eles serão automaticamente iniciados durante a execução.

4. Tela de configuração do SAM 3.1

Configurações do ambiente › cada item do SAM 3.1 (números são Passo 5 para imagens correspondentes).

Entrada conteúdo
1 Pasta raiz do SAM 3.1 Pasta onde os modelos e o ambiente de execução serão armazenados (selecione com 'Referência...').
2 Iniciar automaticamente o servidor SAM 3.1 Habilitado para que, ao iniciar o LoomStroke, os workers também sejam iniciados (a carga do modelo não será realizada até o momento de uso real). O valor padrão é desativado. Mesmo desativado, o LoomStroke será iniciado automaticamente ao executar a função AI Select.
3 Estado Tempo de execução: Pronto, se tudo estiver pronto. Caso faltem elementos, será exibido um código explicativo (Lista）。
Ponto de verificação: nome do arquivo do modelo encontrado (se não houver, 'não detectado').
Trabalhador: running (em execução) / stopped (parado).
Modelo: carregado (já carregado na GPU) / descarregado (não carregado)
CUDA: exibe o nome da GPU em uso durante o início do processo de trabalho.
4 Configurar / Cancelar preparar o ambiente de execução / interromper o preparo em tempo parcial.
5 iniciar / parar / reiniciar Operar o trabalhador manualmente.
6 Carregar modelo / Descarregar modelo Carregar o modelo na memória da GPU / Descarregar o modelo da memória da GPU (o worker continua ativo).
7 log Exibe o processo de configuração e inicialização, bem como o conteúdo e as soluções para erros.
8 Limite de cache de ativos Limite de capacidade para armazenar resultados de análise (como máscaras). De 64 a 262144 MB, valor inicial 2048 MB.

6. tratamento da memória de GPU

O SAM 3.1 carrega o modelo na memória da GPU. Ao executar tarefas que utilizam outras GPUs, como o ComfyUI, é recomendável liberar a memória após o uso para garantir estabilidade.

Panel de Candidatos AI Select: Liberar a memória do SAM Desabilite o modelo da memória da GPU. Ele será automaticamente recarregado na próxima vez que você o usar.
Configurações do ambiente › SAM 3.1 › 'Descarregar modelo'mesmo valor.
Configurações do ambiente › SAM 3.1 › 'Parar'desliga o trabalhador (será automaticamente reiniciado na próxima execução).

7. o que fazer quando não funcionar

caso falhe, será exibido no log [コード] 内容 e os métodos de tratamento serão exibidos. Os logs detalhados estão em ルートフォルダー\runtime\logs\setup.log（configuração）e worker.log está presente (durante a execução).

código Significado Ação
ROOT_NOT_CONFIGURED Pasta raiz não definida configurações do ambiente › selecione a pasta raiz no SAM 3.1.
ROOT_INVALID Pasta inexistente / impossível de escrever Escolha uma pasta existente e acessível para escrita.
SETUP_REQUIRED o ambiente de execução ainda não está disponível execute a configuração.
CHECKPOINT_MISSING Modelo não encontrado / modelo não compatível com SAM 3.1 Passo 3 de acordo com sam3.1_multiplex.pt e coloque o arquivo de configuração na pasta raiz..pt se houver mais de um, moverá os desnecessários.
PYTHON_UNSUPPORTED Não foi encontrado Python 3.12 ou superior Passo 1 Instale o Python aqui (deve ser encontrado pelo py launcher).
NETWORK_CONSENT_REQUIRED Permissão de download não concedida Passo 4 em 'Permitir serviços de IA externos' e Aplicar Faça isso e, em seguida, configure novamente (a mensagem exibe 'Privacy', mas as configurações estão na página da interface).
VENV_CREATE_FAILED não é possível criar um ambiente dedicado verifique a quantidade de espaço livre no disco e os permissões da pasta e reinicie.
PIP_FAILED não é possível preparar o pip Realizar novamente a configuração.
TORCH_INSTALL_FAILED Falha na instalação do PyTorch verifique a rede e o arquivo setup.log e reinicie.
SAM31_INSTALL_FAILED Falha na instalação ou teste de funcionamento do SAM 3 verifica o setup.log. A instalação offline é capítulo 8。
CUDA_UNAVAILABLE GPU (CUDA) não disponível Verifique a GPU NVIDIA e os drivers. O uso apenas da CPU não resultará em velocidade prática.
CUDA_MISMATCH PyTorch e o driver CUDA não são compatíveis Atualize o driver NVIDIA e, em seguida, realize novamente a configuração.
WORKER_START_FAILED O worker não inicia verifique o arquivo worker.log.
HEALTH_FAILED Iniciado, mas não responde Tente reiniciar; se não funcionar, verifique o arquivo worker.log.
MODEL_LOAD_FAILED falha ao carregar o modelo Verifique o worker.log. Se o arquivo do modelo estiver corrompido, reescreva-o.
OOM memória GPU insuficiente Feche aplicativos que utilizam GPU como o ComfyUI ou libere a memória deles antes de reiniciá-los.
COMPATIBILITY_UNSUPPORTED versão do SAM 3 instalada não é compatível Aguarde a atualização do LoomStroke ou informe ao desenvolvedor.
CANCELLED cancelamento da instalação Clique novamente em 'Configurar' para reiniciar a partir do ponto seguinte.

Em casos em que aparece uma mensagem como "SAM 3.1 is not set up" ao usar o AI Select com uma ferramenta, isso está alinhado com o código da tabela acima. Verifique a seção de configuração do ambiente › Estado do SAM 3.1.

8. instalação e remoção offline

instalar o SAM 3 offline

no GitHub facebookresearch/sam3 conjunto completo (pyproject.toml pasta (contendo) ルートフォルダー\runtime\sam3-src Ao colocar aqui, o SAM 3 será instalado a partir desse local. No entanto, componentes como PyTorch precisam ser baixados da rede.

remover

  1. Configurações do ambiente › Em SAM 3.1, clique em 'Parar' para interromper o worker.
  2. Remove completamente a pasta raiz (ambientes dedicados, modelos e tudo isso estão contidos apenas nela, sem afetar o LoomStroke em si ou outros ambientes Python).
  3. Configurações do ambiente › deixe o campo de pasta raiz do SAM 3.1 vazio e clique em OK.

As condições de uso do modelo SAM 3.1 podem ser verificadas na página do Hugging Face: facebook/sam3.1.
