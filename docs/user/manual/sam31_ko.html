SAM 3.1 설치 가이드

LoomStroke의 AI SelectSAM 3.1을 사용하기 위해 필요한 준비 방법을 설명합니다. 작업은 약 30분에서 1시간 정도 소요되며(인터넷 속도에 따라 더 오래 걸릴 수 있습니다).

1. SAM 3.1이란 무엇인가?

SAM 3.1은 메타가 공개한 이미지 영역 분할(세그멘테이션) AI입니다. LoomStroke에서는 다음 기능이 이를 사용합니다.

  • AI 선택 도구: '머리카락', '인물' 등의 단어나 클릭을 통해 선택 범위의 후보를 생성합니다.
  • AI Select Candidates 패널：발견된 후보의 합성 및 레이어화.
  • Manga Mask Assistant 패널: 만화 페이지에서 코마, 편지, 인물 등의 마스킹을 하나로 묶어 생성합니다.

SAM 3.1은 LoomStroke 본체와 별도로특수 실행 환경자신의 PC에서 작동하는 작은 서버로 작동합니다. LoomStroke의 '설정' 버튼이 이 환경을 자동으로 생성하지만,모델 본체(체크포인트)는 스스로 다운로드하여 저장해야 합니다필요합니다. LoomStroke는 모델을 자동으로 다운로드하지 않습니다.

SAM 3.1은 이미지를 외부로 보내지 않고, 모두 자신의 PC 내에서 처리합니다. 인터넷을 사용하는 것은 설치 시 필요한 구성 요소(예: PyTorch 등)를 다운로드하거나 모델을 획득할 때만입니다.

2. 필요한 것

항목내용
OSWindows 10 / 11（64 bit）
GPUNVIDIA 제작 GPU(CUDA 지원)을 강력히 권장개발 시 검증(RTX 4090)에서는 이미지 1장 처리 시 GPU 메모리를 최대 약 4.6GB까지 사용했습니다. GPU 메모리가 8GB 이상이면 안심할 수 있습니다.
GPU가 없더라도 설치는 진행되지만, 최종 동작 테스트에서 'CUDA를 사용할 수 없습니다'라고 표시되어 멈춥니다(단순히 CPU만으로는 실용적인 속도를 얻을 수 없습니다).
NVIDIA 드라이버새 드라이버. 설치는 CUDA 13.0 버전의 PyTorch를 설치하기 위해 명령 프롬프트에서 nvidia-smi 을 실행하여 상단 우측의 'CUDA 버전'이 13.0 이상 을 확인하세요. 부족한 경우 NVIDIA 공식 사이트에서 드라이버를 업데이트합니다.
PythonPython 3.12 이상（3.13 권장）。LoomStroke 외에도 PC에 설치되어 있어야 합니다（단계 1）。
디스크 공간참조 15GB 이상（모델 약 3.5GB + PyTorch 등 수GB + 작업용）.
인터넷설치 시에만 필요(PyTorch로 수 GB의 다운로드가 있습니다).
Hugging Face 계정모델을 다운로드하기 위해 필요(무료)

3. 설치 절차

단계 1: Python 3.12 이상 설치

  1. python.org Python 3.13(또는 3.12)의 Windows용 설치 프로그램을 다운로드합니다.
  2. 설치 프로그램을 실행하고,「py launcher」Python 런처가 들어가는 설정 상태로 설치합니다.
  3. 명령 프롬프트에서 다음 명령을 실행하고,Python 3.13.x 이렇게 표시되면 완료됩니다. 
    py -3.13 --version

설치는 py -3.13 → py -3.12 → py -3 → python 순서대로 Python을 찾아, 3.12 이상의 첫 번째 버전을 사용합니다.

단계 2: SAM 3.1을 위한 폴더 생성

모델과 실행 환경 저장루트 폴더을 만듭니다. 많은 여유 공간을 가진 드라이브에반각 영문 숫자만인 경로이를 사용하여 생성하는 것이 추천됩니다.

例：D:\SAM31

이 폴더에, 단계 3에서 모델을 저장하고, 단계 5의 설정에서 실행 환경(runtime 폴더)가 자동으로 생성됩니다.

단계 3: 모델(체크포인트)을 확보

SAM 3.1 모델은 Hugging Face의 facebook/sam3.1 에서 공개되어 있습니다. 이 페이지는접근 동의가 필요합니다(가드 적용)입니다.

  1. Hugging Face 계정을 생성하고 로그인합니다.
  2. facebook/sam3.1 을 열고 이용 약관을 읽고, 연락처 공유에 동의하여 접근을 요청합니다. 승인까지는 약간 기다려야 할 수 있습니다.
  3. 승인 후, '파일 및 버전' 탭에서 리포지토리의 전체 파일（sam3.1_multiplex.pt(약 3.5 GB)과 config.json 등의 설정 파일)을 다운로드하고, 단계 2의 폴더에 저장합니다.

명령어에 익숙한 경우, Hugging Face 공식 도구를 사용해 한 번에 가져올 수 있습니다(브라우저에서 접근 승인을 받은 후 실행합니다).

py -3.13 -m pip install -U huggingface_hub
hf auth login
hf download facebook/sam3.1 --local-dir D:\SAM31

hf auth login 이제 Hugging Face 설정 화면(접근 토큰)에서 생성한 읽기용 토큰을 붙입니다.hf 명령이 없을 경우, Python 설치 시 'Python.exe를 PATH에 추가'를 켜고 다시 설치하거나, 브라우저에서 다운로드하세요.

모델은 루트 폴더 아래에 있거나 checkpoints·model 서브 폴더에 저장할 수 있습니다. 파일 이름이 sam3.1_multiplex.pt 이면 그걸 사용하고, 다른 이름이면 .pt 파일이 하나뿐일 때만 사용합니다(여러 개가 있는 경우를 판단할 수 없어 '찾을 수 없음'으로 처리됩니다). LoomStroke는 모델을 복사하거나 이동하지 않습니다.

단계 4: LoomStroke에서 외부 서비스에 연결을 허용합니다

설정 중에 PyTorch 등을 다운로드하기 위해 통신을 허용합니다.

  1. 편집 › 환경 설정（Ctrl+,을 열고,1인터페이스를 선택합니다.
  2. 2'외부 AI 서비스(ComfyUI, LLM Gateway, NanoBanana)를 허용'을 켭니다.
  3. 3적용 버튼을 누르면 저장됩니다.설치는 저장된 설정을 확인하므로, 켜놓은 상태만으로는 '네트워크 허용이 필요'로 멈추게 됩니다.

단계 5: 설정을 실행합니다.

  1. 환경 설정의 왼쪽 목록에서 SAM 3.1 을 선택합니다.
  2. 1'SAM 3.1 루트 폴더'의 '참조...'를 통해 단계 2의 폴더를 선택합니다.3상태의 '체크포인트'에 파일 이름이 표시되면 모델이 찾았습니다.
  3. 4설치을 누릅니다.7로그 창에 진행 상황이 흐르며, 다음 10단계가 순차적으로 진행됩니다
단계내용소요 시간 예상
1. 폴더 확인루트 폴더가 존재하고 쓰기 가능함을 확인하고,runtime·logs·state 폴더를 만듭니다.즉시
2. Python 확인Python 3.12 이상을 검색합니다.즉시
3. 환경 설정SAM 3.1용 가상 환경(runtime\venv)을 만듭니다. LoomStroke 본체 환경에 직접 접근하지 않습니다1분 정도
4. pip 준비부품을 넣는 도구(pip)를 준비합니다.즉시
5. PyTorch 설치NVIDIA GPU를 감지하면 CUDA 버전, 그렇지 않으면 CPU 버전의 PyTorch를 다운로드하여 설치합니다.몇 분 ~ 몇 십 분（수 GB）
6. SAM 3.1 설치필요한 구성 요소와 SAM 3 프로그램(GitHub의 facebookresearch/sam3)을 설치합니다.몇 분
7. 모델 확인루트 폴더에 모델이 있는지 확인합니다(다운로드는 하지 않습니다).즉시
8. 동작 테스트모델을 로드하고 SAM 3.1용 모델인지, GPU(CUDA)가 사용 가능한지 확인합니다.몇 분
9. 워커 시작SAM 3.1의 처리 역할(워커)을 시작합니다.수십 초

로그의 마지막에 「SAM 3.1 Ready」이렇게 표시되면 완료입니다.3상태 열이 '런타임: 준비됨', '체크포인트: sam3.1_multiplex.pt', '워커: 실행 중'과 같은 상태가 되며, GPU 이름(CUDA)도 표시됩니다.OK 환경 설정을 닫습니다.

중간에 실패하거나4취소를 누르더라도, 다시 '설정'을 누르면완료된 단계는 건너뛰고 다음부터 진행다시 시도합니다. 처음부터 다시 시작하는 것은 아닙니다.

단계 6: 동작을 확인하기

  1. 캔버스에 이미지를 열고 도구바에서 AI Select 선택합니다(선택 그룹 버튼을 장시간 누름)
  2. 속성 바의 '프롬프트'에 찾고자 하는 내용(예:hair、person、flower)을 설치하고 'Run'을 클릭합니다.
  3. 추천 항목이 색상으로 표시되면 성공입니다. 'Apply'를 클릭하면 선택된 영역이 됩니다.

첫 번째 실행은 모델(약 3.5GB)을 GPU에 로드하기 때문에 약간 시간이 걸립니다. 워커가 멈추고 있다면 실행 시 자동으로 시작됩니다.

4. SAM 3.1 설정 화면

환경 설정 › SAM 3.1의 각 항목입니다(번호는단계 5 의 이미지에 대응).

항목내용
1SAM 3.1 루트 폴더모델과 실행 환경을 저장할 폴더(참조...으로 선택).
2SAM 3.1 서버 자동 시작활성화되면 LoomStroke 실행 시 워커도 시작됩니다(모델 로딩은 실제로 사용할 때까지 수행되지 않습니다). 초기값은 비활성화입니다. 비활성화 상태에서도 AI Select 실행 시 자동으로 시작됩니다.
3상태 런타임준비가 되면 Ready입니다. 부족한 항목이 있으면 이유를 설명하는 코드가 표시됩니다 (목록）。

워커: running(실행 중) / stopped(정지 중)

CUDA: 워커 시작 중에 사용 중인 GPU 이름을 표시합니다.
4설치 / 취소실행 환경을 준비하거나 중간에 중단합니다.
5시작 / 중지 / 재시작워커를 수동으로 제어합니다.
6모델 로드 / 모델 언로드모델을 GPU 메모리에 로드 / GPU 메모리에서 해제(워커는 계속 동작합니다).
7로그 창설치 및 시작 과정, 오류 내용과 해결 방법을 표시합니다

   ├ logs\worker.log           ← ワーカーのログ
   └ state\

6. GPU 메모리 관리

SAM 3.1은 모델을 GPU 메모리에 로드하여 사용합니다. ComfyUI 등 다른 GPU를 사용하는 작업과 동시에 실행할 경우, 사용 후 메모리를 비우면 안정성이 향상됩니다.

AI Select Candidates 패널의 'SAM 메모리 해제'모델을 GPU 메모리에서 제거합니다. 다음에 사용할 때 자동으로 다시 로드합니다.
환경 설정 > SAM 3.1의 '모델 해제'상기와 동일
환경 설정 › SAM 3.1의 '정지'워커 자체를 종료합니다(다음 실행 시 자동으로 시작됨).

7. 잘 되지 않을 때

실패하면 로그 창에 [コード] 内容 과 대처 방법이 표시됩니다. 자세한 로그는 ルートフォルダー\runtime\logs\setup.log（설정）과 worker.log실행 시에 있습니다.

코드의미대처
ROOT_NOT_CONFIGURED루트 폴더가 설정되지 않음환경 설정 › SAM 3.1에서 루트 폴더를 선택합니다.
ROOT_INVALID폴더가 없거나 저장할 수 없습니다존재하고, 쓰기 가능할 폴더를 선택합니다.
SETUP_REQUIRED실행 환경이 아직 없음설치를 실행합니다.
CHECKPOINT_MISSING모델이 없음 / SAM 3.1용 모델이 아님단계 3 그대로 sam3.1_multiplex.pt 과 설정 파일을 루트 폴더에 저장합니다..pt 여러 개가 있는 경우 불필요한 것을 이동합니다.
PYTHON_UNSUPPORTEDPython 3.12 이상이 발견되지 않음단계 1 Python을 설치합니다(py launcher에서 찾을 수 있어야 합니다).
NETWORK_CONSENT_REQUIRED다운로드 허용이 없음단계 4 에서 '외부 AI 서비스 허용'을 켜고적용이후 다시 설정을 진행합니다(메시지에는 'Privacy'가 표시되지만, 설정은 인터페이스 페이지에 있습니다).
VENV_CREATE_FAILED특수 환경을 만들 수 없음디스크의 사용 가능 용량과 폴더 권한을 확인한 후 다시 실행합니다.
PIP_FAILEDpip을 준비할 수 없습니다다시 설치합니다.
TORCH_INSTALL_FAILEDPyTorch 설치 실패네트워크 및 setup.log를 확인한 후 다시 실행합니다.
SAM31_INSTALL_FAILEDSAM 3 본체 설치 또는 작동 테스트에 실패setup.log를 확인합니다. 오프라인 설치는8장。
CUDA_UNAVAILABLEGPU(CUDA) 사용 불가NVIDIA GPU와 드라이버를 확인합니다. CPU만으로는 실용적인 속도를 얻을 수 없습니다.
CUDA_MISMATCHPyTorch와 드라이버의 CUDA가 맞지 않음NVIDIA 드라이버를 업데이트한 후 다시 설정합니다.
WORKER_START_FAILED워커가 시작되지 않음worker.log를 확인합니다.
HEALTH_FAILED시작되었지만 응답하지 않음재시작을 시도하고, 실패하면 worker.log를 확인합니다.
MODEL_LOAD_FAILED모델 로딩에 실패worker.log를 확인합니다. 모델 파일이 손상되어 있다면 다시 설치합니다.
OOMGPU 메모리 부족ComfyUI 등 다른 GPU를 사용하는 애플리케이션을 종료하거나 그 메모리를 해제한 후 다시 실행합니다.
COMPATIBILITY_UNSUPPORTED입력된 SAM 3 버전이 지원되지 않습니다.LoomStroke 업데이트를 기다려야 하거나, 개발자에게 보고해야 합니다.
CANCELLED설치를 취소했습니다또한 '설정'을 다시 누르면 이전에서부터 다시 시작합니다.

AI Select에서 도구를 사용할 때 'SAM 3.1 is not set up' 등의 메시지가 나타나는 경우도 위 표의 코드에 대응합니다. 환경 설정 > SAM 3.1 상태란을 확인해 주세요.

8. 오프라인 설치 및 삭제

SAM 3 본체를 오프라인으로 설치합니다.

GitHub의 facebookresearch/sam3 의 전체 세트 (pyproject.toml 을 포함한 폴더)를 ルートフォルダー\runtime\sam3-src 여기에 놓이면 SAM 3 본체는 여기에서 설치됩니다. 그러나 PyTorch 등의 구성 요소는 네트워크에서 다운로드가 필요합니다.

삭제

  1. 환경 설정 › SAM 3.1에서 '정지' 버튼을 누르고 워커를 멈춥니다.
  2. 루트 폴더를 전체적으로 삭제합니다(특수 환경이나 모델도 이 폴더 안에만 존재하므로, LoomStroke 본체나 다른 Python에 영향을 주지 않습니다).
  3. 환경 설정 > SAM 3.1의 루트 폴더 항목을 비우고 OK를 누릅니다.

SAM 3.1 모델의 이용 조건은 Hugging Face의 facebook/sam3.1 페이지에서 확인해 주세요.
