LoomStroke

用於漫畫和插畫製作的一體化數字繪畫應用程序

應用概覽

LoomStroke 是一款數字繪畫應用，可在同一個创作工作区中整合栅格繪畫、矢量路径、文本编辑、多頁面、外部插件和 AI 聯動。工作文件可以保存為.lstroke格式。

主要功能

  • 支持壓感和倾斜的笔刷引擎
  • 圖層不透明度和混合模式管理
  • 矢量路徑和 參數化 形状
  • 橫向和縱向文本
  • 非破壞性效果圖層
  • 多頁面文档

AI 集成

  • ComfyUI 工作流集成
  • NanoBanana (Gemini) 图像生成
  • 提示词编辑器和片段管理
  • LLM Gateway (打開AI / Anthropic / Gemini)

界面佈局

主窗口由以下区域組成。各面板可通过拖放自由排列，也可以合并為標籤頁。

區域内容

左 停靠區工具栏、颜色面板、字体面板和頁面面板
置中畫布（默认使用基于 QImage 的 SimpleCanvasService）+ 標尺
右 停靠區圖層面板、形状管理器、變換、效果和预覽
浮動上下文工具栏，在描邊后自動顯示

Window 可從菜單顯示或隱藏各個面板。F11 會切換到全屏模式。

混合模式s

圖層混合控制所選圖層如何與下方圖層合成。不透明度會作用于整個混合結果。它只改變顯示合成而不编輯像素，因此适合用于顏色調整、添加光影和叠加纹理。

群組模式描述
組僅穿透用於組。 項目 子 圖層在 項目 的圖層下方， 而不是的 項目 它们 內部 組。
正常正常標准 合合。 上方 圖層是 放置 作為-是， 帶有不透明度 控製 其 强度。
正常Dissolve將半透明區域顯示為随机点状。适合粗糙邊缘和颗粒感表現。
變暗變暗優先采用上下圖層中較暗的成分。适合在抑制亮部的同時添加阴影和暗部。
