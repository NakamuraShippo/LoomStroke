LoomStroke

Интегрированное приложение для цифровой живописи, манги и иллюстраций

Обзор приложения

LoomStroke — приложение для цифровой живописи, объединяющее растровое рисование, векторные контуры, редактирование текста, многостраничность, внешние плагины и интеграцию AI в единой рабочей среде. Рабочие файлы можно сохранять в.lstrokeформате.

Ключевые функции

  • Движок кистей с поддержкой нажима и наклона
  • Управление непрозрачностью слоя и режимом наложения
  • Векторные контуры и параметрические фигуры
  • горизонтальный и вертикальный текст
  • неразрушающий эффект слои
  • Многостраничные документы

AI интеграция

  • ComfyUI рабочий процесс интеграция
  • Генерация изображений NanoBanana (Gemini)
  • Редактор промптов и управление фрагментами
  • LLM Gateway (OpenAI / Anthropic / Gemini)

Свойства инструмента панель панель

Панель настроек активного инструмента. Есть два режима: строка под меню и панель внутри дока.

компоненты

  • пресет строка: пресет выделение комбинированный поле + сохранить/удалить кнопки
  • элемент элемент группа: размер, непрозрачность, жёсткость, интервал, поток, и элемент элемент инструмент настройки
  • Свойства инструмента группа: инструмент-конкретный параметры
  • Действия элемент: инструмент-конкретный действие кнопки и элемент

автоматическое виджет генерация: элемент/int -> ползунок, элемент -> флажок, элемент -> комбинированный поле, цвет -> цвет кнопка

ДействиявводNotes

Поворот холстаизображение меню90° по часовой / 90° против часовой / 180°. преобразует все слои как история группа.

элемент элемент: по умолчанию холст является QImage-основанный SimpleCanvasService . слои может быть растровый, векторный, или маска слои; во время растровый элемент, off-холст области являются также сохранено посредством offset_x/y .

линейки и направляющие холст

  • линейки: показано на верх и лево края из холст. элемент может быть px / mm / элемент.
  • создать направляющие: перетащить из элемент на холст
  • переместить направляющие:Щёлкните и перетащите направляющую
  • удалить направляющие: перетащить за пределы холста
  • переключатель отображать: RКлавиша переключает видимость направляющих
  • привязка: автоматическое привязка к направляющие, сетка, опорные точки, и края
  • Цвет направляющих: элемент в настройки (по умолчанию: #00B7FF)

Сетка холст

  • переключатель отображать: G ключ
  • Сетка размер: по умолчанию 32 px, элемент из 1 к 5000 px в Параметры
  • Сетка привязка: может быть включено в переместить инструмент и похожий инструменты

.lstroke родной формат файл

.lstroke является ZIP-основанный родной формат. на сохранить, это элемент к *.lstroke.tmp и элемент элемент цель файл. элемент элемент является сохранено:

  • JSON манифест (элемент и документ метаданные)
  • PNG изображение данные для каждая слой
  • векторный объект данные
  • страница элемент (v1.1 элемент-страница)
  • UI макет снимок
  • ICC цвет элемент
