LoomStroke

만화와 일러스트 제작을 위한 통합 디지털 페인팅 애플리케이션

애플리케이션 개요

LoomStroke는 래스터 페인팅, 벡터 경로, 텍스트 편집, 여러 페이지, 외부 플러그인, AI 연동을 하나의 제작 작업 공간에 통합한 디지털 페인팅 애플리케이션입니다. 작업 파일은.lstroke형식으로 저장할 수 있습니다.

주요 기능

  • 필압과 기울기를 지원하는 브러시 엔진
  • 레이어 불투명도 및 블렌드 모드 관리
  • 벡터 경로 및 파라메트릭 도형
  • 가로 및 세로 텍스트
  • 비파괴 효과 레이어
  • 다중 페이지 문서

AI 연동

  • ComfyUI 워크플로 연동
  • NanoBanana (Gemini) 이미지 생성
  • 프롬프트 편집기 및 스니펫 관리
  • LLM Gateway (OpenAI / Anthropic / Gemini)

화면 레이아웃

메인 창은 아래 영역으로 구성됩니다. 각 패널은 드래그 앤 드롭으로 자유롭게 배치할 수 있으며 탭으로 결합할 수도 있습니다.

영역내용
상단메뉴 바 + 도구 속성 바, 활성 도구 설정을 한 줄로 표시
왼쪽 도크도구 모음, 색상 패널, 글꼴 패널 및 페이지 패널
가운데캔버스(기본값: QImage 기반 SimpleCanvasService) + 눈금자
오른쪽 도크레이어 패널, 도형 관리자, 변형, 효과 및 미리보기
플로팅컨텍스트 도구 모음, 스트로크 후 자동 표시

Window 각 패널은 메뉴에서 표시하거나 숨길 수 있습니다.F11 전체 화면 모드로 전환합니다.
