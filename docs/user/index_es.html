LoomStroke

Una aplicación integrada de pintura digital para la producción de manga e ilustración

Resumen de la aplicación

LoomStroke es una aplicación de pintura digital que integra pintura ráster, trazados vectoriales, edición de texto, varias páginas, plugins externos e integración de IA en un único espacio de producción. Los archivos de trabajo se pueden guardar en.lstrokeformato.

Funciones principales

  • Motor de pincel compatible con presión e inclinación
  • Gestión de opacidad de capas y modos de fusión
  • Trazados vectoriales y formas paramétricas
  • Texto horizontal y vertical
  • no destructivo efecto capas
  • Documentos multipágina

Integración con IA

  • Integración de flujos de trabajo de ComfyUI
  • Generación de imágenes NanoBanana (Gemini)
  • Editor de prompts y gestión de fragmentos
  • LLM Gateway (OpenAI / Anthropic / Gemini)

Barra de herramientas panel

Lista vertical de botones de herramientas situada en el borde izquierdo. Cada botón representa un grupo de herramientas; una pulsación larga de 350 ms abre un menú desplegable para elegir variantes.

el diseño cambia automáticamente entre vertical y horizontal como el panel ancho cambios. El tamaño del iconoo es 48x48 px.

Propiedades de la herramienta panel panel

Panel que muestra los ajustes de la herramienta activa. Tiene dos diseños: modo barra bajo la barra de menús y modo panel dentro de un dock.

Componentes

  • Preset fila: Preset selección combo cuadro + guardar/eliminar botones
  • Common Properties grupo: tamaño, opacidad, Hardness, Spacing, Flow, y other common herramienta ajustes
  • Propiedades de la herramienta grupo: herramienta-specific parámetros
  • Acciones container: específicos de la herramienta botones de acción y casillas

automático control generación: float/int -> deslizador, bool -> casilla, enum -> combo cuadro, color -> color botón

Modos de fusión

La fusión de capas controla cómo se compone la capa seleccionada con las capas inferiores. La opacidad se aplica después a todo el resultado fusionado. Como solo cambia la composición visibles sin editar píxeles, resulta útil para ajustar color, añadir luz o sombra y superponer texturas.

GrupoModoDescripción
grupo soloPasar a travéspara grupos. Composites child capas en el context de el capas inferiores, en lugar de isolating them dentro el grupo.
normalnormalestándar composición. el superior capa es colocada como-es, con opacidad controlando su intensidad.
normalDissolveMuestra las zonas translúcidas como puntos aleatorios. Útil para bordes ásperos y aspecto granulado.
OscurecerOscurecerPrioriza los componentes más oscuros de las capas superior e inferior. Útil para añadir sombras y zonas oscuras mientras se reducen las partes claras.
OscurecerMultiplicarMultiplica los colores para oscurecerlos. Es el modo de oscurecimiento más sencillo para line art, sombras, textura de papel y capas de suciedad.
OscurecerSubexposición de colorOscurece intensamente la base como si la quemara, aumentando saturación y contraste. Adecuado para sombras profundas y texturas fuertes.
OscurecerSubexposición linealOscurece reduciendo la luminancia de forma lineal. Produce zonas oscuras fuertes y más matemáticas que Color Burn.
OscurecerColor más oscuroElige el color más oscuro entre las capas superior e inferior en lugar de mezclarlas. El resultado se parece a una sustitución de color con prioridad al oscuro.
AclararAclararPrioriza los componentes más claros de las capas superior e inferior. Úsalo para añadir luz o brillos eliminando partes oscuras.
AclararTramaFunciona en dirección opuesta a Multiply y aclara de forma natural. Adecuado para resplandores, brillos, humo y recursos de luz.
AclararSobreexposición de coloraclara el base intensamente y crea vívida light. esto puede clip a blanco easily, so ajustar con opacidad.
AclararSobreexposición lineal (Añadir)añade colores a brighten intensamente. útil para light sources, magia efectos, y intenso resplandor.
AclararColor más claroElige el color más claro entre las capas superior e inferior. Úsalo al superponer recursos con prioridad a colores claros.
contrasteSuperponercambia entre Multiply y Screen basado en el brillo de el base. un estándar opción para añadiendo textura y reforzar shading.
contrasteLuz suaveañade contraste more suavemente que Overlay. adecuado para piel, tela, y sutil shading adjustments.
contrasteLuz fuerteAñade efectos fuertes de luz y oscuridad basados en la capa superior. Crea brillos y sombras definidos.
contrasteLuz intensacrea fuerte, vívida contraste similar a un combinación de Color Burn y color Dodge.
contrasteLuz linealCambia la luminancia de forma intensa y lineal, como una combinación de Linear Burn y Linear Dodge.
contrasteLuz focalCompone como si sustituyera zonas oscuras y claras. Adecuado para texturas duras y efectos especiales.
contrasteMezcla definidaempuja colores hacia un intensamente posterizado resultado. útil para poster-like, ruidoso, o experimental efectos.
InversiónDiferenciamuestra el diferencia entre el superior y inferior capas. útil para alineación comprobaciones, de aspecto invertido efectos, y inusual color cambios.
InversiónExclusiónun más suave diferencia fusión que diferencia. adecuado para especial efectos con un less inverted sensación.
InversiónSustraerResta el color superior de la base para oscurecerla. Útil para efectos de eliminación de color y efectos oscuros especiales.
InversiónDividiraclara como si dividing el base por el superior color. útil para corrección, extracción, y checking fuerte highlight cambios.
ComponenteTonoaplica solo el superior tono a el base mientras conservando base luminance y saturación. usar esto cuando you solo quieres a cambiar tono.
ComponenteSaturaciónAplica solo la saturación superior a la base. Úselo para añadir viveza o reducir la saturación.
Componentecoloraplica el superior tono y saturación a el base mientras conservando base luminance. adecuado para coloring grayscale shading.
ComponenteLuminosidadaplica solo el superior luminance a el base mientras conservando base tono y saturación. Replaces solo shading o brillo.

fusión modos affect el mostrado resultado de capas, efecto capas, grupo composición, y PSD exportar. Changing un modo recomposites el lienzo but does no rewrite el capa píxeles themselves.

Cuando se selecciona una capa de efecto en el panel de capas, el nombre del efecto aparece en el título del cuadro de grupo y se generan cuadros de selección para cada parámetro. Los cambios se reflejan inmediatamente en la vista previa y admiten Deshacer.

AI efecto capa AI efecto

AI efecto capa es una función que coloca.lsfx preajustes en el lienzo como capas y luego envía capas de entrada y parámetros a ComfyUI Gateway o NanoBanana Gateway para generar imágenes. Funciona con el panel de capas, el panel de efectos y AI efectos Manager, separado de los paneles normales de ComfyUI y NanoBanana.

básicas flow

  1. desde el AI menú, elegir AI efecto Presets... a abrir AI efectos administrador
  2. derecha-clic un preset y elegir Agregar capa AI efecto
  3. en el panel de capas, asigne capas de entrada a las filas de Slot debajo de la capa de efecto AI
  4. usar el panel de efectos a controlar parámetros, destino de salida, y generar
  5. Aplicar el resultado generado a el AI efecto propia capa o a un nuevo salida capa directamente encima de ella
ElementoContenido
capa tipolayer_type="ai_effect"
Preset formato.lsfx. el ZIP contiene el manifiesto, Gateway ajustes, iconos, y datos relacionados
compatible GatewayComfyUI Gateway / NanoBanana Gateway
Guardar.lstroke v1.2 ai_effect payload stores estado

Las pasarelas que requieren acceso a servicios externos solo se ejecutan cuando los servicios externos están permitidos en Preferencias y la clave API o la configuración de conexión necesarias están configuradas.

Generación y estado AI efecto

Cuando se selecciona una capa de efecto AI, el panel de efectos muestra parámetros dinámicos del preajuste. La generación se registra en el historial como un comando y admite Deshacer/Rehacer.

panel de capas / panel de efectos

ElementoDescripción

Exclusion botónAlterna un Slot de entrada para excluirlo de la fusión y usarlo solo como entrada de IA.
Generarinicia generación desde el seleccionado capa o desde el AI efecto fila en el panel de capas.
salida a esto capacuando activado, salida es escrita de vuelta a el AI efecto propia capa. cuando desactivado, un nuevo salida capa es creada directamente encima de ella.
Progress / cancelarMientras se ejecuta se muestra el progreso, y la cancelación externa se gestiona mediantecancel_layer(layer_id) .

  • Cuadrícula tamaño: predeterminado 32 px, configurable desde 1 a 5000 px en Preferencias

Formato nativo .lstroke archivo

.lstroke es un ZIP-basado nativo formato. en guardar, esto writes a *.lstroke.tmp y luego reemplaza el archivo de destino. Se guarda la siguiente información:

  • manifiesto JSON (versión y metadatos del documento)
  • PNG imagen data para each capa
  • vectorial objeto data
  • página information (v1.1 multipágina)
  • Instantánea del diseño de la UI
  • ICC color profile
