LoomStroke

An integrated digital painting application for manga and illustration production

Application Overview

LoomStroke is a digital painting application that brings raster painting, vector paths, text editing, multiple pages, external plugins, and AI integration into one production workspace. Working files can be saved in .lstroke format.

Key Features

  • Pressure and tilt-aware brush engine
  • Layer opacity and blend mode management
  • Vector paths and parametric shapes
  • Horizontal and vertical text
  • Non-destructive effect layers
  • Multi-page documents

AI Integration

  • ComfyUI workflow integration
  • NanoBanana (Gemini) image generation
  • Prompt editor and snippet management
  • LLM Gateway (OpenAI / Anthropic / Gemini)

Blend Modes

Layer blending controls how the selected layer is composited with the layers below it. Opacity is applied afterward to the whole blended result. Because it changes only the displayed composite without editing pixels, it is useful for color adjustment, adding light or shadow, and overlaying textures.

GroupModeDescription
Group onlyPass ThroughFor groups. Composites child layers in the context of the layers below, instead of isolating them inside the group.
NormalNormalStandard compositing. The upper layer is placed as-is, with opacity controlling its strength.
NormalDissolveDisplays translucent areas as randomized dots. Useful for rough edges and grainy looks.
DarkenDarkenPrioritizes the darker components of the upper and lower layers. Useful for adding shadows and dark areas while suppressing bright parts.
DarkenMultiplyMultiplies colors to darken them. This is the easiest darkening mode for line art, shadows, paper texture, and grime overlays.
DarkenColor BurnDarkens the base strongly as if burning it in, while increasing saturation and contrast. Good for deep shadows and strong textures.
DarkenLinear BurnDarkens by lowering luminance linearly. Produces strong, more mathematical dark areas than Color Burn.
DarkenDarker ColorChooses the darker color from the upper and lower layers rather than blending them. The result is close to dark-priority color replacement.
LightenLightenPrioritizes the brighter components of the upper and lower layers. Use it to add light or highlights while removing darker parts.
LightenScreenWorks in the opposite direction of Multiply and brightens naturally. Good for glow, highlights, smoke, and light assets.
LightenColor DodgeBrightens the base strongly and creates vivid light. It can clip to white easily, so adjust with Opacity.
LightenLinear Dodge (Add)Adds colors to brighten strongly. Useful for light sources, magic effects, and intense glow.
LightenLighter ColorChooses the brighter color from the upper and lower layers. Use it when overlaying assets with light-color priority.
ContrastOverlaySwitches between Multiply and Screen based on the brightness of the base. A standard choice for adding texture and strengthening shading.
ContrastSoft LightAdds contrast more softly than Overlay. Good for skin, fabric, and subtle shading adjustments.
ContrastHard LightAdds strong light and dark effects based on the upper layer. Creates clear highlights and shadows.
ContrastVivid LightCreates strong, vivid contrast similar to a combination of Color Burn and Color Dodge.
ContrastLinear LightChanges luminance strongly and linearly, similar to combining Linear Burn and Linear Dodge.
ContrastPin LightComposites as if replacing dark and bright regions. Best for special hard textures and effects.
ContrastHard MixPushes colors toward a strongly posterized result. Useful for poster-like, noisy, or experimental effects.
InversionDifferenceShows the difference between the upper and lower layers. Useful for alignment checks, inverted-looking effects, and unusual color shifts.
InversionExclusionA softer difference blend than Difference. Good for special effects with a less inverted feel.
InversionSubtractSubtracts the upper color from the base to darken it. Useful for color-removal effects and dark special effects.
InversionDivideBrightens as if dividing the base by the upper color. Useful for correction, extraction, and checking strong highlight changes.
ComponentHueApplies only the upper hue to the base while preserving base luminance and saturation. Use it when you only want to change hue.
ComponentSaturationApplies only the upper saturation to the base. Use it to add vividness or reduce saturation.
ComponentColorApplies the upper hue and saturation to the base while preserving base luminance. Good for coloring grayscale shading.
ComponentLuminosityApplies only the upper luminance to the base while preserving base hue and saturation. Replaces only shading or brightness.

Blend modes affect the displayed result of layers, effect layers, group compositing, and PSD export. Changing a mode recomposites the canvas but does not rewrite the layer pixels themselves.

AI Effect Layer AI EFFECT

AI Effect Layer is a feature that places.lsfx presets on the canvas as layers, then sends input layers and parameters to a ComfyUI Gateway or NanoBanana Gateway to generate images. It works with the Layer Panel, Effect Panel, and AI Effects Manager separately from the normal ComfyUI and NanoBanana panels.

Basic flow

  1. From the AI menu, choose AI Effect Presets... to open AI Effects Manager
  2. Right-click a preset and choose Add AI Effect Layer
  3. In the Layer Panel, assign input layers to Slot rows under the AI Effect layer
  4. Use the Effect Panel to control parameters, output destination, and Generate
  5. Apply the generated result to the AI Effect layer itself or to a new output layer directly above it
ItemContents
Layer typelayer_type="ai_effect"
Preset format.lsfx. The ZIP contains the manifest, Gateway settings, icons, and related data
Supported GatewayComfyUI Gateway / NanoBanana Gateway
Save.lstroke v1.2 ai_effect payload stores state

Gateways that require external service access can run only when external services are allowed in Preferences and the required API key or connection settings are configured.

Implementation note: The default Canvas is the QImage-based SimpleCanvasService . Layers can be raster, vector, or mask layers; during raster movement, off-canvas areas are also preserved by offset_x/y .

Rulers and Guides CANVAS

  • Rulers: Shown on the top and left edges of the canvas. Units can be px / mm / inch.
  • Create guides: Drag from a ruler onto the canvas
  • Move guides: Click and drag a guide line
  • Delete guides: Drag out of the canvas
  • Toggle display: R key toggles guide visibility
  • Snap: Automatic snapping to guides, grid, anchors, and edges
  • Guide color: Configurable in settings (default: #00B7FF)

Grid CANVAS

  • Toggle display: G Key
  • Grid size: Default 32 px, configurable from 1 to 5000 px in Preferences
  • Grid snap: Can be enabled in the Move tool and similar tools

.lstroke Native Format FILE

.lstroke is a ZIP-based native format. On save, it writes to *.lstroke.tmp and then replaces the target file. The following information is saved:

  • JSON manifest (version and document metadata)
  • PNG image data for each layer
  • Vector object data
  • Page information (v1.1 multi-page)
  • UI layout snapshot
  • ICC color profile
