LoomStroke bundled CMYK ICC profiles -- checked 2026-10-10

These are third-party profiles, supplied as unmodified original bytes.
Their own licenses apply separately from the LoomStroke application license.
Original ICC descriptions and copyright tags are preserved. catalog.json
records the source, description, byte count, SHA-256, and printing condition.

Europe / ISO printing conditions:
  ISO Coated v2 300% and ISO Coated v2 (basICColor): FOGRA39 coated paper.
  PSO Uncoated ISO12647 (basICColor): FOGRA47 uncoated paper.
  ISO Newspaper v4 26 (basICColor): newspaper printing.
  PSO LWC Improved (basICColor): FOGRA45 improved lightweight coated paper.
  SC paper (basICColor): FOGRA40 supercalendered paper.
  License: LICENSE-ZLIB-bICC.txt, from the basICColor printing profile package
  mirrored by Debian icc-profiles-free 2.4. These are basICColor profiles;
  do not represent them as the similarly named ECI originals.

Hong Kong / Asia, ISO 12647-2:2013 offset printing:
  APTEC Offset Coated LinearCTV 2025: premium coated paper, TAC 320%.
  APTEC Offset Uncoated LinearCTV 2025: wood-free uncoated paper, TAC 280%.
  License: LICENSE-APTEC.txt, reproduced from the original ICC copyright tags.

Select a profile according to the printer's specified printing condition
and paper, rather than the user's country. A similarly named profile may
use different black generation, ink limits, or characterization data.
Print-shop supplied profiles can still be loaded with Load ICC Profile.

This bundle does not contain Japan Color, ECI PSO v3, Adobe, GRACoL/SWOP
originals, or experimental Amethyst equivalents. They require separate
redistribution review or permission. Regional coverage is not exhaustive.
No profiles are downloaded at runtime or installed into OS profile folders.
