# プロンプトエディタープラグイン

Prompt Editor は保存済みスニペットを組み合わせてプロンプトを作成し、ライブラリ管理や LLM 送信を行うワークスペースです。

## 開き方
1. LoomStroke を起動します。
2. `ウィンドウ > Prompt Editor` を選択（表示されない場合は `ウィンドウ > パネル` で有効化）。
3. ドック／フロートは自由です。位置は次回起動時も保持されます。

## 画面概要
- **Compose タブ**: `String`, `List`, `Text`, `Prompt` を組み合わせ、プレビューを確認して保存します。
- **Library タブ**: 検索／タグ／タイプで絞り込み、タイトル・タグ・タイプ・本文を編集できます。
- **LLM タブ**: LLM 設定、System/User プロンプト入力、送信と出力確認を行います。

## プロンプト作成手順
1. Text Editor で必要なスニペットを用意します（更新は即座に同期されます）。
2. Compose タブで **New** を押し、コンポーネントを追加して構成します。
3. プレビューを確認し、**Save / Save As** でテンプレートとして保存します。
4. Library タブで保存済みプロンプトを選択し、詳細を編集・複製・削除します。
5. LLM タブで System/User プロンプトのリストから選択し、必要なら調整して送信します。

## 連携について
- Text Editor と Prompt Editor はイベントバスで接続されており、スニペット更新は即反映されます。

## ヒント
- タグでスニペットを整理すると候補が見つけやすくなります。
- List コンポーネントはスタイルやプリセットの選択に適しています。
- Library タブの Export でテンプレートを共有できます。

## トラブルシューティング
- コンポーネント候補が古い場合は Text Editor 側が自動保存されているか確認し、必要ならパネルを再表示して下さい。
- セーブできない場合は少なくとも 1 つ以上のコンポーネントが追加されているかチェックします。
